# 개발 계획

범위: 정파 + 검객 (SPEC.md "개발 범위" 참고)

## 기술 방향
- HTML + JavaScript(모듈) + Canvas, 빌드 도구·외부 라이브러리 없음 → GitHub Pages에 그대로 배포 가능
- 게임 로직(src/core)과 화면(src/ui)을 분리 → 로직은 Node 기본 테스트로 자동 검증
- 화면 기준 960x540(16:9), 도트가 흐려지지 않게 정수배 확대
- 도트는 코드 안에 픽셀 배열로 직접 그림 (나중에 이미지 파일로 교체 가능하게)

## 1단계: 전투 한 판 (MVP) ✅ 완료
목표: 검객 vs 적 한 번의 전투가 처음부터 끝까지 돌아감
- [x] 프로젝트 뼈대 (index.html, 폴더 구조, 실행 방법)
- [x] 전투 로직: 덱 섞기 → 5장 뽑기 → 내공 3 → 카드 사용 → 턴 종료 → 적 행동 → 반복
- [x] 카드 3종: 기본 검법(공격), 호신강기(방어), 특수 초식 1종
- [x] 적 2종 + 다음 초식 예고 표시
- [x] 승리 / 패배 판정, 다시 하기
- [x] 쿼터뷰 비무대 바닥 + 검객/적 32x32 도트 (임시 그림)

## 2단계: 한 판(런) 구조 🔄 2-A 완료, 2-B 대기
범위를 둘로 나눔. 2-A를 먼저 끝내고 재미를 확인한 뒤 2-B 진행.

### 2-A: 1구역(후기지수 비무대회) 한 판이 처음부터 두목까지 돌아감 ✅
- [x] 한 판 상태 관리 (체력 유지, 덱, 은자, 현재 위치) — src/core/run.js + 테스트
- [x] 갈림길 지도 생성 — src/core/map.js + 테스트
  - 6층 + 두목, 층마다 2~4칸, 갈림길로 연결. 시드로 매번 다른 지도
  - 1층은 항상 전투, 두목 바로 앞 층은 항상 운기조식, 고수는 3층부터
- [x] 지도 화면 (두루마리 느낌, 갈 수 있는 칸만 선택 가능)
- [x] 칸 종류
  - ⚔️ 일반 전투: 은자 10~20 + 비급 3장 중 1장 (건너뛰기 가능)
  - 💀 고수: 더 강한 적, 은자 25~35 + 좋은 비급 확률↑
  - 🧘 운기조식: 체력 30% 회복 또는 카드 1장 연마(강화)
  - 🏮 객잔: 비급 구매, 카드 제거(쓸수록 비싸짐)
  - ❓ 기연: 선택지가 있는 짧은 사건 3~4종 (예: 떨어진 비급, 취한 노고수와의 내기)
  - 👹 두목: 1구역 마지막 상대
- [x] 검객 카드 확장: 기본 3종 → 약 15종 (일반/고급/희귀) + 각 카드의 연마(+) 버전
- [x] 상태 효과 3종 (카드가 다양해지려면 필요)
  - 기세: 공격 피해 증가 / 내상: 받는 피해 증가 / 기혈 흐트러짐: 주는 피해 감소
- [x] 적 확장: 일반 4종, 고수 2종, 두목 1종 (아래 그림 필요)
- [x] 결과: 두목 처치 = 1구역 돌파 화면 / 쓰러짐 = 패배 후 새 판 (회귀는 3단계)
- [x] 밸런스 목표: 1구역 한 판 약 10~12분 (3구역 합쳐 30분)

### 2-B: 2·3구역 (무림맹 사파 토벌, 마교 침공 저지)
- [ ] 구역별 적·두목·기연 추가, 구역이 넘어갈 때 연출

### 필요한 그림 (2-A)
| 역할 | 디자인 | 상태 |
|---|---|---|
| 일반: 곽진 | 정파 권사 | ✅ |
| 일반: 낭인 마철 | 사파 검객 | ✅ |
| 일반: 흑도 주먹패 | 사파 권사 | ✅ |
| 일반: 대회 감찰 밀정 | 정파 살수 | ✅ |
| 고수: 외눈 살수 | 사파 살수 | ✅ |
| 고수: 정체불명의 복면객 | 마교 살수 | ✅ |
| 두목: 우승 후보로 위장한 마교 첩자 | 마교 검객 | ✅ |
그림이 늦어도 개발은 진행 (없는 캐릭터는 실루엣으로 표시)
