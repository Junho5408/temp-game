# 개발 계획

범위: 정파 + 검객 (SPEC.md "개발 범위" 참고)

## 기술 방향
- HTML + JavaScript(모듈) + Canvas, 빌드 도구·외부 라이브러리 없음 → GitHub Pages에 그대로 배포 가능
- 게임 로직(src/core)과 화면(src/ui)을 분리 → 로직은 Node 기본 테스트로 자동 검증
- 화면 기준 960x540(16:9), 도트가 흐려지지 않게 정수배 확대
- 도트는 코드 안에 픽셀 배열로 직접 그림 (나중에 이미지 파일로 교체 가능하게)

## 1단계: 전투 한 판 (MVP) 🔄 승인 대기
목표: 검객 vs 적 한 번의 전투가 처음부터 끝까지 돌아감
- [ ] 프로젝트 뼈대 (index.html, 폴더 구조, 실행 방법)
- [ ] 전투 로직: 덱 섞기 → 5장 뽑기 → 내공 3 → 카드 사용 → 턴 종료 → 적 행동 → 반복
- [ ] 카드 3종: 기본 검법(공격), 호신강기(방어), 특수 초식 1종
- [ ] 적 2종 + 다음 초식 예고 표시
- [ ] 승리 / 패배 판정, 다시 하기
- [ ] 쿼터뷰 비무대 바닥 + 검객/적 32x32 도트 (임시 그림)
- [ ] 마우스 클릭 + 터치로 카드 사용
- [ ] 로직 테스트 + 실제 화면 스크린샷 확인

## 2단계: 한 판(런) 구조
- [ ] 갈림길 지도 (1구역 후기지수 비무대회, 6~7칸)
- [ ] 칸 종류: 일반 전투 / 고수 / 운기조식 / 객잔 / 기연 / 두목
- [ ] 승리 보상: 비급 3장 중 1장, 은자
- [ ] 카드 종류 확장, 초식 연마(강화)
- [ ] 2·3구역 (무림맹 사파 토벌, 마교 침공 저지)

## 3단계: 화면 흐름 + 회귀
- [ ] 타이틀 화면
- [ ] 1회차 프롤로그 겸 튜토리얼 (객잔 객사)
- [ ] 세력 + 계열 선택 화면 (정파 검객만 열림, 나머지는 잠금 표시)
- [ ] 사망 → 회귀 → 무공 1개 기억 → 다음 회차에 들고 시작
- [ ] 저장 (기억한 무공, 깨달음)

## 4단계: 꾸미기
- [ ] 도트 그래픽 다듬기 (마음에 안 들면 사용자 제공 그림으로 교체)
- [ ] 공격·피격 애니메이션, 데미지 숫자, 화면 흔들림
- [ ] 8비트 효과음

## 5단계: 다듬기 & 배포
- [ ] 밸런스 조정 (한 판 약 30분)
- [ ] 모바일 터치 점검
- [ ] GitHub Pages 배포
