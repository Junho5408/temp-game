# 초안: 회귀물다운 스토리 개편 (백일취)

## 개요
- **무엇**: 회귀의 원인(백일취)을 정본에 넣고 이야기 전체에 엮는다.
  - 프롤로그의 한 잔 → 회귀 직후 대사(직전 죽음·단서 수·엔딩 뒤) → 주노의 의심·힌트·고백 → 回 선택지 6개 → 일반 엔딩(고리가 안 끊김) → 진엔딩(고리가 끊김)
- **위치**: 모든 세력 공통.
  - 프롤로그: 1회차 객잔
  - 회귀 직후: 매 생 시작
  - 주노 기연: 정파 1·3구역
  - 진소하 기연: 정파 1·2구역, 사파 2구역
  - 回 선택지: 정파 juno·sooha·soohaCamp, 사파 innkeeperDebt·soohaAmbush, 마교 cultElder
  - 엔딩: 그날 밤 객잔
- **진상 겹과의 관계**: 백일취는 진상 세 겹과 따로 노는 '회귀의 겹'이다.
  - 귀면 뒤의 배신자(3겹)가 남아 있으면 원한이 풀리지 않는다 → 일반 엔딩에서도 고리가 끊기지 않는다.
  - 3겹을 밝혀야(진엔딩) 고리가 끊긴다.
- 백일취 단서(`wine`)는 진상 조각으로 세지 않는다(TRUE_CLUES 는 그대로, 회귀 직후 단서 수에서도 뺌).

## 정본 변경 제안 (docs/STORY.md) — 사용자 결정(A안·일반 엔딩=고리 유지)을 따름. 본문 전체가 이 제안을 따른다

### 1) 새 절 "회귀의 비밀 ✅" — "시간 구조" 절 바로 위에 넣는다
```
## 회귀의 비밀 ✅ (2026-11-27 사용자 결정: 백일취)
- **원인: 백일취(百日醉).** 프롤로그 그날 밤, 주노가 주인공에게 따라 준 술 한 잔.
  주인공은 마지못해 받아 마셨다 ("노인이 따른 잔을 물리면 재수가 없다네").
- **규칙**
  1. 마신 자가 원한을 품고 죽으면, 죽은 날이 언제든 **술을 마신 그날 밤으로부터 백 일 전 아침**에 눈을 뜬다.
  2. 한 번 마시면 원한이 풀릴 때까지 깨지 않는다. 다시 마실 필요는 없다.
  3. 몸은 돌아가고 기억은 남는다 (게임: 기억한 무공, 알아낸 단서).
  4. **원한이 풀리면 고리가 끊긴다.** 살아남는 것만으로는 안 된다. 그날 밤의 진상을 밝혀 억울함이 사라져야 한다.
  5. 마신 자에게선 '오래 묵힌 술 냄새'가 난다. 백일취를 겪어 본 자만 맡는다.
     돌수록 냄새가 짙어진다 = "술이 익는다". 원한이 풀린 순간이 "술이 잘 익은" 때.
- **한 판 = 한 생.** 회차는 "몇 번째 생", 대사는 "이번 생".
- **주노의 과거**
  - 아주 오래전 같은 술을 마시고 같은 백 일을 몇 번이고 산 사람. 몇 번인지는 세다가 말았다.
  - 끝내 원한을 풀고 고리를 끊었다.
  - 무엇에 대한 원한이었는지, 술을 누구에게서 받았는지는 말하지 않는다 (💡 나중 이야기 여지).
  - 주노는 지금 회귀하지 않는다 → 지난 회차를 '기억'하지는 못한다.
    대신 술 냄새로 주인공이 돌고 있다는 것, 그 술을 자기가 따랐다는 것을 안다. 이것이 "알아보는 듯한" 정체.
  - 따른 이유: 흰 옷에 검을 차고 하필 밀사 곁에 앉은 젊은이 — "오늘 밤 억울하게 갈 얼굴".
    말로는 경고했고("흰 옷은 비 오는 날…"), 듣지 않을 걸 알아서 한 잔을 따랐다.
- **알게 되는 때**
  - 주노 3번째 만남부터: 자기 과거만 고백한다.
  - 단서 `wine`: 술 이름과 규칙 (정파 1구역 주노 기연의 回 선택지, `note` 필요).
  - 진엔딩: 주노가 전부 털어놓는다.
- 💡 진엔딩 뒤에도 판은 계속할 수 있다. 다시 시작하면 "노인네가 한 잔 더 따랐다"는 농담으로 처리한다 (정본 줄거리는 진엔딩에서 끝).
```

### 2) "시간 구조" 절 수정
- 지금: "도중에 죽으면 다시 백 일 전으로…"
- 바꿀 문장: "원한을 품고 죽으면 다시 백 일 전으로. 그날 밤을 넘겨 살아남아도 원한이 남아 있으면(일반 엔딩) 새벽에 정신을 잃고 백 일 전 아침으로. **기억한 무공 1개**와 **알아낸 단서**는 남음"

"2~6줄 — 회차, 직전에 나를 죽인 적(두목·고수), 알아낸 단서 수, 일반 엔딩 뒤인지에 따라 달라짐"

### 4) 등장인물 표의 주노 칸
"늘 취해 있는 노고수. 그날 밤 주인공에게 **백일취**를 따라 준 장본인. 자신도 오래전 같은 술로 회귀를 겪었다. 술 냄새로 주인공을 알아본다 → 유머 담당이자 회귀의 비밀을 쥔 조력자"

### 5) 새 줄 "미래를 아는 자의 선택지 ✅"
"이야기 기연에 `needClue` 선택지 — 회귀 기록이 그 단서를 알 때만 보이고 回 표시. 지난 생의 지식으로 먼저 손을 써서 기존 선택지보다 조금 나은 보상."

### 6) "엔딩" 절 전체 교체
```
## 엔딩 ✅
- **일반 엔딩 — 고리는 끊기지 않는다** (어느 세력이든 3구역 돌파 + 귀면 처치):
  - 귀면은 "누가 우리를 보냈는지 아느냐…"를 남기고 죽는다. 나는 처음으로 살아서 새벽빛을 본다.
  - 그러나 보낸 자가 남아 억울함이 풀리지 않았다. 새벽에 정신을 잃고 다시 백 일 전 아침에 눈을 뜬다 ("…아니, 아직이다").
  - 진엔딩 힌트는 이야기 속 말로 ("한 길만 걸어서는 안 보이는 대답", "…아직, 끝나지 않았다").
- **진엔딩 — 고리가 끊긴다** (세 길의 핵심 단서를 모두 모은 뒤 귀면 → 백리현 처치):
  - 밀사 진소하를 구하고 밀서로 배신자를 밝힌다. 원한이 풀리자 백일취도 깬다.
  - 주노가 백일취와 자기 과거를 털어놓는다. 국수를 끝까지 먹는다. 처음으로 백 일 뒤의 아침.
```

### S-4 주노 (n = 만난 횟수, juno·junoGate 합산)
1. **n=1, 의심**: 지금 대사 그대로 ("꿈에서였나?")
2. **n=2, 힌트**
   - 주노: 또 그 얼굴이군. 이상하지, 자네만 보면 술이 확 깨는 기분이야.
   - 주노: (킁킁) …그리고 자네한테선 술 냄새가 나. 오래 묵힌 놈으로, 딱 한 잔.
   - 나: …마신 적 없습니다. 오늘은.
   - 주노: 오늘은, 이라. 허허. 앉게, 앉아. 한 번 크게 데인 얼굴이구먼.
3. **n≥3, 고백 — 백일취를 모를 때** (자기 과거만 말한다)
   - 지문: 노인이 웬일로 호리병을 내려놓았다. 눈빛이 맑다.
   - 주노: 자네, 몇 번째 아침인지 세다가 그만뒀지? 나도 그랬네.
   - 나: …노인장도?
   - 주노: 아주 오래전 일이야. 같은 백 일을, 같은 원한을 안고 몇 번이고 살았지.
   - 주노: "백 일"이란 숫자가 어디서 또 나오는지 알게 되면, 그때 물어보게. (딸꾹)
   - 이 줄은 `note` 단서와 回 선택지로 이어지는 길잡이다.
4. **n≥3, 백일취를 안 뒤**: 짧은 대사 3가지가 돌아가며 나온다 ("술은 원한을 먹고 익는다네…", "깨지. 술이든, 꿈이든.")
5. **관문(junoGate), 백일취를 안 뒤**
   - 나: 백일취는 아직 깨지 않았습니다.
   - 주노: 그건 술이 아니라 자네가 정하는 거야. 그날 밤, 누가 자네를 죽였는지 끝까지 아는가?

### S-4 진소하 기시감 (n = 만난 횟수, sooha·soohaCamp·soohaAmbush 합산)
- 비무대회 n≥3: 사내의 "……"가 "……우리, 어디서 본 적 있소?"로 바뀐다.
  - envoy 를 알면 다음 두 줄을 붙인다: "…실례지만, 우리 어디서 본 적 있소?" / 나: (있지. 당신은 기억 못 하겠지만.)
- 막사 n≥3: "…이상하군. 처음 보는 얼굴인데, 목소리가 귀에 익소." / 나: (진소하. 그날 밤, 내 대신 살아 나간 사내의 이름.)
  - n≥6 이면 한 줄 더: "우리… 어디서 본 적 있소? 비 오는 밤 꿈에서 본 얼굴 같기도 하고."
- 산길 n≥3
  - 지문: 흰 옷의 사내가 문득 이쪽 숲을 돌아본다. 누가 있는 줄 안다는 듯이.
  - 나: (…설마. 기억할 리가 없다.)

### S-5 진엔딩
- TRUE_BRIDGE 끝에 한 줄: 주노: (딸꾹) 젊은이. 이번엔 하나도 남기지 말고 다 풀고 가게.
- TRUE_ENDING 순서
  1. 밀서
  2. "국수 먹던 떠돌이."
  3. 가슴에 박힌 오래된 것이 풀림
  4. 주노 "…풀렸구먼."
  5. 백일취 고백 3줄
  6. "왜 하필 나였습니까" → "오늘 밤 억울하게 갈 얼굴이더군" → (…그럼 말리든가.) → "말렸잖나. 흰 옷은 비 오는 날 입는 게 아니라고."
  7. 복이 국수 → 국수를 끝까지 먹음 ("생각보다 짰다")
  8. 주노 "이번엔 술이 잘 익었군" → (…끝까지 술 얘기군, 이 노인네.)
  9. 처음으로 백 일 뒤의 아침

function wakeResolve(clues) {
  if (Object.values(TRUE_CLUES).every((id) => clues.includes(id))) {
    return { who: 'me', text: '흰 학의 전낭, 혈영대를 부른 서찰, 맹의 높은 자리. 조각은 다 모였다. 이번 생에서 끝낸다.' };

}

### events.js — 도우미 (heal 함수 아래에 추가)
```js
// 무작위 카드 1장 연마 (없으면 null) — 미래를 아는 자의 선택지에서 씀
function upgradeOne(run, rng) {
  const options = run.deck.filter(canUpgrade);
  if (options.length === 0) return null;
  const card = options[Math.floor(rng() * options.length)];
  card.upgraded = true;
  return CARDS[card.id].name;
}
```

## 스스로 점검
- **정본과 모순 없음**
  - 회귀는 항상 그날 밤으로부터 백 일 전이다. 백일취 규칙("그날로부터")과 맞는다.
  - 주노가 "알아보는 듯한" 것은 기억이 아니라 냄새라서, 1회차 대사("꿈에서였나?")와 어긋나지 않는다.
  - 진엔딩 조건(TRUE_CLUES)은 그대로 두었다.
- **단서를 얻기 전에 진상을 말하지 않음**
  - 백일취의 이름과 규칙은 `wine` 단서(回 선택지) 또는 진엔딩에서만 나온다. 3번째 만남의 주노는 자기 과거만 말한다.
  - 回 선택지는 모두 그 단서를 이미 아는 사람에게만 보인다. 선택지 안의 말도 그 단서 범위를 넘지 않는다(흰 학 = 맹 수뇌부는 `payer` 본문과 같음).
  - 직전 죽음 대사는 전투 전 대사에서 이미 나온 정보만 쓴다. 백리현 이름은 진 단서 3개를 다 모은 판에서만 그와 싸우므로 문제없다.
  - 일반 엔딩은 배신자를 말하지 않고 "한 길만 걸어서는…"으로 돌려 말한다.
- **인물 말투**
  - 나: 짧게, 속마음은 괄호로 투덜 ("…그럼 말리든가", "어디 가서 말도 못 하겠군")
  - 복이: "손님", 수다
  - 주노: 딸꾹, 허허, 능청
  - 진소하: ~하오/~소/~리다
- **한 줄 90자 이하**: 모든 대사·결과 문구를 \n 단위로 기계 검사해서 통과했다. 화자 id 도 모두 SPEAKERS 에 있다.
- **오리지널**: 백일취, 술 냄새로 회귀자를 알아보는 설정, 대사 모두 새로 썼다. 쓴 무협 용어는 일반 용어(혈공·연마 등)뿐이다.
- **알려 둘 점**
  - 단서 `wine` 은 지금 정파 길(주노 기연)에서만 얻는다. 사파·마교에 주노 기연을 둘지는 다음 작업 후보.
  - 체력이 가득일 때 "체력을 0 회복했다"가 나온다. 기존 주노 선택지와 같은 방식이라 그대로 두었다.
