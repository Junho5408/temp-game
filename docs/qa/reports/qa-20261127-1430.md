# QA 보고서 · qa-20261127-1430 (8단계: 류파 개편 · 9개 길)

**결론: 치명 0, 높음 0, 보통 10(기능 2·저장 1·화면 1·밸런스 6), 낮음 7입니다. 배포 전에 BUG-050·051·053·054 네 건을 고치기를 권합니다. BUG-052 는 BUG-051 과 같은 줄이라 함께 고칩니다.** 진행이 막히거나 멈추는 문제는 없었습니다. 오류·NaN·음수 자원·손패 글자 넘침도 한 건도 나오지 않았습니다.

- BUG-050(보통): 마교 이야기 기연 「혈공 장로의 시험」은 권사·살수 판에도 검객 무공 『피의 맹세』를 줍니다. 8단계 원칙("내 세력·내 계열 무공만")에 어긋납니다.
- BUG-051(보통, 저장): 8단계 이전 사파·마교 판 저장을 이어하면 판이 '검객'이 됩니다. 덱은 살수·권사 카드인데 보상·객잔·주인공 그림은 검객 것이 나옵니다.
- BUG-053(보통, 화면): 마교 살수·사파 살수의 대사창 초상에 머리 윗부분만 나옵니다(코·입이 안 보임).
- BUG-054(보통): 연타 공격 도중 반격으로 두목이 2단계에 들어가거나 광폭이 켜지면, 같은 공격의 남은 타가 예고보다 세게 들어옵니다. BUG-038(함정판)을 반격 쪽에서 다시 겪는 것입니다.
- 밸런스는 계열 평균이 대부분 기준 안입니다. 다만 같은 계열 안에서 류파 사이 격차가 큽니다(1구역 13~70%). 이번 밸런스 티켓은 모두 **적용하기 전에 사용자 승인**을 받습니다.
- QA 중에 게임 코드는 바꾸지 않았습니다. 수치 실험은 메모리 안에서만 했습니다.
- 지난 티켓 BUG-001~049 는 모두 수정된 상태이고, 이번에 다시 생긴 것은 없습니다. 관련만 있는 닫힌 티켓(BUG-029·033·034·035·038·042·043·047)은 새 티켓 안에 "관련"으로 적었습니다.

## 사용자가 정할 것
1. **호신으로 피해가 0이면 맞은 것인가 (BUG-055)**
 - A안 (추천): 막으면 안 맞은 것으로 칩니다. 독·흐트러짐·약화가 붙지 않습니다. 천잠보의, 흡혈, 마기와 기준이 같아지고, 풀이("받는 피해를 막음")와도 맞습니다.
 - B안: 지금처럼 둡니다. 대신 호신·독수 풀이에 "막아도 독·흐트러짐은 묻는다"라고 적습니다.
2. **발도의 기준 (BUG-063)**
 - A안 (추천): "이번 턴 첫 **초식**"으로 바꿉니다. 심법·행낭 물품을 먼저 써도 발도가 남습니다. 손으로 따로 세야 하고, 검기는 지금 셈을 그대로 씁니다.
 - B안: 규칙은 그대로 두고 낭인 수치만 올립니다(BUG-058 의 낭인 안, 실측 24.2 → 38.3%).
3. **기억한 무공의 범위 (BUG-066)**
 - A안 (추천): 지금처럼 어느 판에나 가져가게 둡니다(PROGRESS.md 278줄 결정). 기억 칸에 "다른 계열" 표시만 넣고, 8단계 뒤에도 유지한다는 결정을 PROGRESS 에 한 줄 남깁니다.
 - B안: 같은 세력·계열 판에서만 기억 무공을 고를 수 있게 막습니다.
4. **밸런스 수치 승인**: BUG-056~065 의 제안 수치를 그대로 넣을지 정합니다. 특히 BUG-056 은 마교 권사 최종이 24.3% 로 내려가는 문제를 함께 풀어야 합니다.

## 티켓으로 만들지 않은 것
- **개선 제안**
- 전투 화면 '나' 아래 설명이 계열과 상관없이 "<세력> · 떠돌이 무인"입니다(src/main.js:608). "정파 살수"처럼 세력과 계열을 함께 보여 주면 지금 길을 알아보기 쉽습니다. (F-FN-05)
- 류파 격차 기준을 문서로 남기기를 권합니다. 예: "같은 계열 안 류파는 강제 판 1구역이 자연 판 ±8%p(대략 32~48%) 안". docs/SPEC.md 의 밸런스 기준이나 이 폴더 README 에 둡니다. (F-BA-01)
- 저장 검증에서 `maxHp: 1e12` 도 통과합니다. 손으로 고친 저장에서만 생기므로 상한(예: 999)을 둘지는 BUG-052 를 고칠 때 함께 정하면 됩니다.
- **조정하지 않음 (정보)**
- 고수·두목: 한소(사파 3구역)는 체력을 105 → 95 로 낮춰도 효과가 작고, 3구역 돌파율이 기준 안입니다. 당철은 권사에게만 세서 BUG-059 를 넣은 뒤 다시 봅니다. 혜광 15.5%(마교 권사)는 경계입니다. 각성의 "평균 피해 0~2.8"은 흡혈·승리 회복 때문에 생긴 착시입니다. (F-BA-12)
