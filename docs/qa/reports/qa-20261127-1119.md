## 사용자가 정할 것
1. **봇 측정 방식 (BUG-041 에 적음) — A안 / B안**
 - 봇이 심법 유지(power) 무공을 효과 종류와 상관없이 높게 칩니다. 그래서 정파 2구역이 낮은 것 중 약 11%p 는 봇이 보상을 잘못 고른 탓입니다.
 - A안(권장): 봇은 그대로 두고 명경지심만 올립니다(BUG-041). 지금까지 기준을 정한 봇과 같은 봇으로 비교할 수 있습니다.
 - B안: 봇의 power 계산을 고치고 기준을 다시 정합니다. 이때는 BUG-041 을 넣지 **않습니다**. 둘 다 하면 정파 3구역이 75.1% 로 너무 쉬워집니다.
2. **훔치기 규칙 (BUG-044 에 적음) — 수치안 / 하한 규칙안**
 - 수치안(권장): 날강도 훔치기 3→2(연마 4→3), 신투 묘수 연마 5→3. 규칙은 그대로입니다.
 - 하한 규칙안: "적에게 있던 기세만큼만 뺏고, 0 아래로는 안 내려감". 카드 설명과는 더 잘 맞지만 사파 전체가 약해집니다. 이 안은 따로 재지 않았고 수치를 다시 재야 합니다.
3. **함정 점혈 시점 (BUG-045 에 적음) — (a) / (b)**
 - (a) 연출만 맞춤: 배너를 "혈도가 막혔다 · 다음 차례에 굳는다"로 바꿉니다. 밸런스는 그대로입니다.
 - (b) 규칙을 바꿈: 함정으로 굳으면 그 차례 공격을 막습니다. 쇠덫 등이 강해지므로 밸런스를 다시 잽니다.
