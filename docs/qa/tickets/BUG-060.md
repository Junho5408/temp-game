# BUG-060 정파 검객 남궁 류파가 너무 약하고 무당 판의 2구역이 낮음
- 상태: 열림
- 심각도: 보통
- 분류: 밸런스
- 발견: qa-20261127-1430 · F-BA-04, F-BA-11(조식)

## 증상
- 류파 강제 판 1구역: 남궁 **22.5**(pure 13.3), 무당 34.6, 화산 **49.2**.
- 남궁 카드는 한 장 넣으면 손해입니다: 조식 -16.0%p, 계명심법 -8.9, 대하귀해 -5.9.
- 화산 기세 카드는 매우 셉니다: 운기행공 +16.7, 무념무상 +18.3, 봉황연무 +14.3%p.
- 무당 강제 판 2구역이 29.7% 입니다. 정파 검객 자연 판 2구역 36.1% 의 주된 원인입니다.
- 다만 봇이 반격·호신을 높게 쳐서 무당으로 쏠리는 탓도 섞여 있습니다(1구역을 깬 덱의 57%가 무당, 보고서 "도구 문제").
- 정파 검객 자연 판은 39.7 / 36.1 / 60.5 / 60.7 로 3구역·최종이 60 경계입니다.

## 재현 절차
1. `node tools/qa/balance.mjs --faction=orthodox --cls=sword --n=2000 --run=<이름>`
2. 류파 강제: `qa-output/qa-20261127-1430/exp/sim.mjs --school --mode=prefer`

## 기대 / 실제
- 기대: 류파 강제 판 1구역 32~48%, 자연 판 모든 구역 30~60%.
- 실제: 남궁 22.5, 화산 49.2, 무당 2구역 29.7.

## 원인 추정 (바꿀 곳)
- 남궁 검기(swordQi): `src/core/cards-orthodox.js:85/90/129/134/139/178/183`, 규칙 `battle.js:496`
- 조식: `cards-orthodox.js:74` cost 1
- 무당 bonusIfAttacking: `cards-orthodox.js:37/42/107/204`, `cards.js:116` 역류검

## 제안 (메모리 실험, 2000판)
- 남궁 검기 카드 전부 +1: 남궁 강제 판 22.5 → 29.4 / 34.2 / 49.3 / 47.5. (+2는 남궁 37.9% 지만 자연 판 1구역이 46.2% 로 기준을 넘어 권하지 않습니다.)
- 무당 bonusIfAttacking +2, 반격 +1: 무당 강제 판 34.6 / 29.7 → 40.7 / 32.3
- 둘 다 넣은 정파 검객 자연 판: 39.7 / 36.1 / 60.5 / 60.7 → 40.9 / 39.3 / **62.6** / 52.2
- 선택: 조식 비용 1 → 0 (실험하지 않음)
- 화산은 계열 평균이 기준 안이라 그대로 둡니다. 다른 류파를 올려도 격차가 남으면 운기행공 기세 2 → 1(연마 3 → 2), 무념무상 4 → 3 을 후보로 둡니다(실험하지 않음).
- **주의**: 3구역이 62.6% 로 기준 위가 됩니다. 넣은 뒤 다시 재서 넘치면 무당 보강을 +1 로 줄입니다. 봇 보상 점수를 고치면(도구 작업) 무당 쏠림이 줄어드니, 바꾸기 전과 후를 함께 잽니다.
