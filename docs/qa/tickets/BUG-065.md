# BUG-065 귀왕 비도갑(사파 두목 보물)이 검객·권사에게는 거의 쓸모가 없음
- 상태: 수정됨
- 심각도: 낮음
- 분류: 밸런스
- 발견: qa-20261127-1430 · F-BA-13
- 관련: BUG-047 (같은 보물의 "약화" 문구, 수정됨)

## 증상
귀왕 비도갑은 "매 턴 적 흐트러짐 1 + 암기 피해 +2" 입니다. 그런데 8단계에서 암기는 살수만 쓰게 됐습니다. 사파 검객·권사에게는 암기 피해 +2 가 아무 일도 하지 않습니다.
- 처음부터 쥐여 준 실험(1500판)

| 길 | 보물 | 1구역 / 2구역 | 완주 |
|---|---|---|---|
| 사파 검객 | 대환단 | 84.2 / 62.7 | 13.9 |
| 사파 검객 | **귀왕 비도갑** | 39.7 / 62.5 | **8.0** |
| 사파 살수 | 대환단 | | 8.5 |
| 사파 살수 | 귀왕 비도갑 | | 8.8 |

- 살수에게는 대환단과 비슷하지만, 검객에게는 크게 처집니다.

## 재현 절차
1. `qa-output/qa-20261127-1430/exp/sim.mjs --treasure=<보물>`, 결과 `exp/treas.jsonl`

## 기대 / 실제
- 기대: 사파 두목 보물이 세 계열 모두에게 비슷한 값어치입니다.
- 실제: 검객·권사에게는 암기 보너스가 비어 약합니다.

## 원인 추정

## 제안 (둘 중 하나, 실험하지 않음)
- 계열별 효과: 암기가 없는 계열(검객·권사)에서는 "초식 한 타 +1"로 바꿉니다. 설명도 계열에 맞게 보입니다.
- 두목 보물 후보를 계열별로 다르게 냅니다.

## 완료 조건
- 사용자가 안을 고릅니다.
- 사파 세 계열에 귀왕 비도갑을 쥐여 1500판씩 다시 재서, 완주율이 대환단과 비슷한 범위인지 확인합니다.
- 검객·권사 판에서 귀왕 비도갑이 새 효과를 내는지 확인하는 규칙 테스트를 추가합니다.
