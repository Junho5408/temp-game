# BUG-032 다른 길에서 가져온 적의 칭호가 장소와 맞지 않음
- 상태: 수정됨
- 심각도: 낮음
- 분류: 화면
- 발견: qa-20261127-0536 · F-FN-03, F-EX-04

## 증상
적 정의 하나를 여러 길이 같이 써서, 칭호가 그 장소와 안 맞습니다. 칭호는 전투 시작 배너와 이름표에 크게 나옵니다.
- 사파 1구역(흑도 패권 다툼)의 마철: "비무대에 끼어든 낭인"
- 마교 1구역(서열 혈투)의 두칠: "흑도 칼잡이"
- 마교 3구역(정마 결전)의 배교자: "마교에 투항한 낭인" 인데 마교 주인공의 적으로 나옴

## 재현 절차
1. 사파로 출발해 1구역 전투에서 마철을 만납니다.
- 근거: `qa-output/qa-20261127-0536/fn/D03-sapa-hand.png`, `vp-640x360-battle.png`

## 기대 / 실제
- 기대: 칭호가 그 길의 배경에 맞습니다.
- 실제: 처음 정의한 길의 칭호가 그대로 나옵니다.

## 원인 추정
- `src/core/enemies.js:43` ronin 칭호가 `UNORTHODOX_POOLS[0]`(503-504행)에 들어 있습니다.
- `enemies.js:367` gangThug 가 `DEMONIC_POOLS[0].normal`(608행)에 들어 있습니다.
- `enemies.js:238` renegade 가 마교 3구역 normal 에 들어 있습니다.
- 칭호는 `src/main.js:328`(배너)과 534행(이름표)에서 씁니다.

## 완료 조건
- 이미 있는 `ENEMIES.bloodWolfD = { ...ENEMIES.bloodWolf, title: … }`(`enemies.js:602-603`) 방식으로 `roninU`·`gangThugD`·`renegadeD` 변형을 만들어 해당 POOLS 에 넣습니다. 또는 POOLS 항목에서 칭호를 덮어쓸 수 있게 합니다.
- 변형 id 를 쓰면 기록·통계(balance.mjs)에서 id 가 갈라지는 점을 감안합니다.
- 칭호 문구는 사용자 확인을 받습니다.
- 이를 확인하는 테스트를 추가합니다(`tests/routes.test.js`). 세력별 POOLS 의 적 칭호에 다른 길의 장소 낱말("비무대", "투항" 등)이 없는지 목록으로 대조합니다.
