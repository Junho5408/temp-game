# BUG-041 명경지심(정파 두목 보물)이 약해 정파 2구역이 낮음
- 상태: 수정됨
- 심각도: 보통
- 분류: 밸런스
- 발견: qa-20261127-1119 · F-BA-01 (+ F-BA-02 결정 포함)

## 증상
정파만 2구역 돌파율이 낮습니다. 2구역 적은 세 세력이 같은데도 그렇습니다. 그래서 정파는 "뒤로 갈수록 어렵게"가 거꾸로입니다(2구역 35.7 < 3구역 48.7 < 최종 64.3).

| 세력 (3000판) | 1구역 | 2구역 | 3구역 | 최종 |
|---|---|---|---|---|
| 정파 | 40.2 | **35.7** | 48.7 | **64.3** |
| 사파 | 44.2 | 52.0 | 58.3 | 59.0 |
| 마교 | 44.6 | 51.0 | 55.3 | 37.9 |

- 1구역 두목 보상의 맨 앞 칸은 [대환단, 그 세력 두목 보물] 중 무작위 하나입니다(`src/core/run.js:366-369`). 사람도 명경지심이 나온 판에는 대환단을 고를 수 없습니다.
- 1구역 두목 보상을 강제로 고르게 한 실험(1500판, 2구역 돌파율):

| 보상 | 정파 | 사파 | 마교 |
|---|---|---|---|
| 대환단 | 45.4 | 57.0 | 56.1 |
| 세력 두목 보물 | **23.9** (명경지심) | 49.9 (귀왕 비도갑) | 42.9 (마신 혈인) |
| 일반 보물 | 18.7 | 38.6 | 37.2 |

- 명경지심은 일반 보물보다 겨우 +5%p 낫습니다. (45.4 + 23.9) / 2 = 34.7 이 실측 35.7 과 맞습니다.

## 재현 절차
1. `node tools/qa/balance.mjs --n=3000 --faction=orthodox --run=<이름>` 을 돌립니다.
2. 강제 선택 실험: `qa-output/qa-20261127-1119/exp/` 의 `sim.mjs` · `worker.mjs` (결과 r2~r7.jsonl)

## 기대 / 실제
- 기대: 세력 두목 보물은 대환단과 비슷한 값어치이고, 정파 2구역도 사파·마교와 비슷합니다.
- 실제: 명경지심을 들면 2구역 23.9% 로, 대환단(45.4%)의 절반입니다.

## 원인 추정
- `src/core/items.js:231` `mirrorHeart` fx `{ turnStatus: { insight: 1 } }`. 매 턴 간파 1은 "한 장이 1.5배 + 필중" 정도라 내공 +1 같은 보물보다 훨씬 작습니다.

## 제안
- fx 를 `{ turnStatus: { insight: 1 }, attackBonus: 1 }` 로, 설명을 "매 턴 간파 1, 모든 초식 한 타 +1"로 바꿉니다.
- 결과: 강제로 고를 때 2구역 23.9 → 38.0. 보통 판 3000판 40.2 / 43.2 / 60.2 / 59.6, 진엔딩 판 최종 46.6. 1구역은 그대로입니다.
- 시험한 다른 안:

| 안 | 강제 선택 시 2구역 | 보통 판 |
|---|---|---|
| 간파 1 + 경공 1 | 37.1 | 40.2 / 42.0 / 59.2 / 67.0 (최종이 기준 넘음) |
| 간파 1 + 첫 턴 내공 1 | 36.4 | - |
| 간파 1 + 한 타 +2 | 51.5 | 3구역 70.7 (너무 셈) |

## 사용자가 정할 것 — 봇 측정 방식 A안 / B안 (F-BA-02)
밸런스 봇(`tools/qa/balance.mjs:40`, `:57`)은 심법 유지(power) 무공의 숫자를 효과 종류와 상관없이 더해 높게 칩니다. 예: 청맥심법 sv 36, 일반 무공은 9 안팎. 하지만 실제로 덱에 넣으면 효과가 작거나 손해입니다(청맥 +0.5, 정해 -4.0%p). 정파 2구역이 낮은 것 중 약 11%p 는 봇이 보상을 잘못 고른 탓입니다.
- **A안 (권장)**: 봇은 그대로 두고 이 티켓(명경지심 상향)만 넣습니다. 지금까지 기준을 정한 봇과 같은 봇으로 비교할 수 있습니다.
- **B안**: 봇의 power 값을 "각 효과의 가중치 × 값 × 3턴"으로 고칩니다. 고친 봇 3000판: 정파 43.9 / 47.0 / 69.1 / 50.5, 사파 44.6 / 55.3 / 59.4 / 57.5, 마교 48.1 / 61.1 / 59.9 / 33.0. 이 경우 **이 티켓은 넣지 않고** 기준을 다시 정합니다. 둘 다 하면 정파 53.7 / 75.1 / 51 로 3구역이 너무 쉬워집니다.
- 참고: 사람은 청맥심법을 매번 1순위로 고르지 않을 것이므로 실제 정파 2구역은 봇보다 높을 가능성이 큽니다.

## 완료 조건
- 사용자가 A안 또는 B안을 고릅니다. 고른 내용을 PROGRESS.md 에 적습니다.
- A안이면: 명경지심 fx 와 설명을 바꾸고, 정파 3000판에서 2구역 40% 이상, 모든 구역 30~60% 를 확인합니다.
- B안이면: 이 티켓은 "보류"로 바꾸고, 도구 수정과 기준 재설정은 따로 진행합니다.
- 보물 설명과 fx 가 맞는지 확인하는 규칙 테스트를 추가합니다(명경지심을 가지면 첫 턴 간파 1, 초식 한 타 +1).
