# BUG-053 마교 살수·사파 살수 대사창 초상이 머리 윗부분만 나옴
- 상태: 열림
- 심각도: 보통
- 분류: 화면
- 발견: qa-20261127-1430 · F-FN-03

## 증상
대사창의 '나' 초상이 마교 살수와 사파 살수에서만 상투·앞머리·눈까지만 보입니다. 코와 입이 잘립니다. 다른 7칸은 머리부터 턱까지 나옵니다.
- 두 그림만 깊게 웅크린 자세라 그림 높이에 비해 머리가 약 1.4~1.5배 큽니다(그림은 모두 높이 648).
- 마교 권사는 얼굴 오른쪽 아래에 붉은 주먹이 겹칩니다(가벼움).

## 재현 절차
1. 마교 살수(또는 사파 살수)로 출발합니다.
2. 구역 시작 대사에서 '나' 줄의 초상을 봅니다.
- 스크립트: `node qa-output/qa-20261127-1430/fn-portrait.cjs`
- 스크린샷: `fn/dlg-me-5.png`(마교 살수), `fn/dlg-me-8.png`(사파 살수), 비교 `fn/dlg-me-crop-058.png`(왼쪽부터 정파 검객 정상 / 마교 살수 / 사파 살수), 9칸 모음 `fn/dlg-me-all.png`

## 기대 / 실제
- 기대: 9칸 모두 머리부터 턱까지 얼굴이 들어갑니다.
- 실제: 두 칸은 눈까지만 보이고 위쪽으로 치우칩니다.

## 원인 추정
- `src/ui/portraits.js:34` `side = img.height * (F?.size ?? 0.2)`: 얼굴 칸이 그림 높이의 20%로 고정입니다. "서 있는 전신이면 머리가 높이의 약 20%"라고 가정합니다.
- `src/ui/characters.js:34-44` SPRITES: 주인공 9칸 모두 `face` 손보정이 없습니다(적·NPC 는 일부 있음, 예: 123·127·208줄).

## 제안
- SPRITES 의 `demonic-assassin`(39줄), `unorthodox-assassin`(42줄)에 `face: { size: 0.28~0.3 }` 을 넣고 필요하면 y 도 넣습니다.
- face 는 DESIGNS.sprite 로 그대로 전달되므로(60줄) 다른 코드는 바꾸지 않아도 됩니다.
- 마교 권사는 x 만 손볼지 보고 정합니다.
- 주의: portraits.js:57 은 `F.x * img.height`, 즉 높이 기준 비율입니다.

## 완료 조건
- 9칸 모두 '나' 초상에 머리부터 턱까지 들어갑니다. `fn-portrait.cjs` 로 찍은 9칸 모음 스크린샷을 사용자가 보고 확인합니다.
- 가능하면 smoke 에 9칸 초상 점검을 추가합니다. 예: 초상 캔버스 아래쪽 1/3 에도 살색 화소가 있는지 봅니다.
