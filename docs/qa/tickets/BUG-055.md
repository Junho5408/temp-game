# BUG-055 호신이 피해를 모두 막아도 독수 중독·흐트러짐이 붙음 (사용자가 정할 것)
- 상태: 수정됨
- 심각도: 낮음
- 분류: 기능
- 발견: qa-20261127-1430 · F-EX-02

## 증상
호신으로 적 공격 피해가 0이 되어도, 적의 독수 특성 중독이나 공격에 붙은 흐트러짐·약화·중독이 그대로 붙습니다.
- 독안귀 독비도 3×3 + 금강불괴(호신 12): 피해 0인데 중독 3이 붙어 다음 턴에 체력 70 → 67 이 됩니다.
- 연무혁 연환 부채 5×2(흐트러짐 1) + 금강불괴: 피해 0인데 흐트러짐 1이 붙습니다.
- 같은 반복문 안에서도 기준이 갈립니다.
- 흡혈과 마기는 피해가 0이면 붙지 않습니다.
- 천잠보의로 막은 타도 "맞지 않은 것"으로 칩니다.
- 풀이도 헷갈립니다. 호신은 "받는 피해를 합계 이만큼 막음", 독수는 "공격이 맞을 때마다 중독 1"이라고 되어 있습니다.

## 재현 절차
1. 독안귀(oneEye)의 독비도 차례에 금강불괴를 쓰고 턴을 넘깁니다.
2. 피해 0, 중독 3 이 붙는 것을 봅니다.
- 스크립트: `node qa-output/qa-20261127-1430/repro-guard-debuff.mjs`, `mech.mjs` [3]·[3b]

## 사용자가 정할 것
- **A안 (추천)**: 호신으로 0이 된 타는 "안 맞은 것"으로 칩니다. 독수 중독과 공격 부가 디버프가 붙지 않습니다.
- 천잠보의·흡혈·마기와 기준이 하나로 맞고, 지금 풀이와도 맞습니다.
- 호신이 조금 강해집니다(권사 판). 고친 뒤 정파·사파 권사를 다시 잽니다.
- **B안**: 지금처럼 둡니다(호신은 피해만 막음). 호신·독수 풀이에 "막아도 독·흐트러짐은 묻는다"를 적습니다.

## 기대 / 실제
- 기대: 정한 규칙대로 동작하고 풀이도 그와 같습니다.
- 실제: 피해 0이어도 독·디버프가 붙고, 풀이에는 그 설명이 없습니다.
