# BUG-015 손패 카드 피해 숫자가 기세를 반영하지 않음
- 상태: 열림
- 심각도: 낮음
- 분류: 화면
- 발견: qa-20261126-0921 · F-FN-05

## 증상
기세 1 인 상태에서도 손패에는 "기본 검법 피해 6", "견제 피해 4" 처럼 기본값이 표시됩니다. 실제로는 7/5 가 들어갑니다. 적 예고 쪽은 실제 값을 보여 줘서 둘이 다릅니다. 간파 칩 설명 "치명: 1" 도 숫자가 무슨 뜻인지 알기 어렵습니다.

## 재현 절차
1. 공청석유로 기세 1 인 상태에서 첫 턴 손패를 봅니다 (`extra-checks2.cjs` Y01).

## 기대 / 실제
- 기대: 실제 피해가 표시되고, 기본값과 다르면 색으로 구분됩니다.
- 실제: 기본값만 표시됩니다.

## 원인 추정
- 손패는 `cardFace`(src/ui/screens.js:15–27) → `describe`(src/core/cards.js:188–190) 의 고정 문구를 씁니다.
- renderHand(main.js:579–)는 명중률만 고칩니다.
- 간파 칩 문구는 main.js:43 에 있습니다.

## 완료 조건
- renderHand 에서 `computeDamage`(battle.js:185, 307)로 계산한 값을 표시하고, 기본값과 다르면 색을 바꿉니다.
- 간파 칩은 "남은 1회" 로 바꿉니다.
- 테스트 추가: core 에 `cardPreviewDamage(s, uid)` 를 두고, 아래 조합에서 미리 보기 값이 playCard 뒤 실제 피해와 같은지 비교합니다 (luck:false).
  - 기세
  - 흐트러짐
  - 내상
  - 연계
  - perAttack
