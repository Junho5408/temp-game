# BUG-034 마름쇠(사파 일반 무공)가 희귀 무공보다 셈
- 상태: 수정됨
- 심각도: 보통
- 분류: 밸런스
- 발견: qa-20261127-0536 · F-BA-03
- 함께 적용: BUG-035, BUG-036 (사파 묶음)

## 증상
마름쇠를 시작 덱에 1장만 넣어도 사파 1구역 돌파율이 42.1% → 65.9%(+23.8%p)로 오릅니다(2000판). 정파 1위 무념무상(희귀, +17.4)과 사파 1위 만천화우(희귀, +23.3)와 같거나 큰데, 등급은 일반입니다.
- 손에 남겨 두기만 해도 턴이 끝날 때 저절로 던져져 피해 3·중독 3 을 주는 것이 핵심입니다.
- 쓸 때 거는 중독(2)은 거의 영향이 없습니다(2→1 로 바꿔도 65.6%).
- 분석가가 400판으로 다시 돌렸을 때도 +24.9%p 였습니다.
