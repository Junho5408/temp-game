# BUG-063 발도가 "턴의 첫 카드"라 심법·물품을 먼저 쓰면 사라짐 (사용자가 정할 것)
- 상태: 수정됨
- 심각도: 보통
- 분류: 밸런스
- 발견: qa-20261127-1430 · F-BA-09 (발도), F-EX 메모(행낭 물품도 첫 카드로 침)

## 증상
발도는 "이번 턴 첫 카드"일 때만 붙습니다. 심법이나 행낭 물품을 먼저 쓰면 그 턴 발도가 사라집니다.
- 일반·고급 발도 카드는 한 장 넣어도 0 근처입니다: 발도 -0.4, 역발도 -1.3, 귀도 -0.4, 섬광 발도 -0.3, 무성발도 -2.3, 영살 +0.4, 암영 발도 -1.5, 혈발도 -0.1, 혈영 습격 0.0. 의미 있는 것은 신속 발도 +12.1, 무영살 +7.6 뿐입니다.
- 발도 규칙을 끈 실험(1구역)
- 정파 살수 -7.3 (시작 덱 암습 ×3 의 발도 2)
- 사파 검객 -0.5
- 낭인 강제 판 -2.8
- 마교 살수 0.0
- 덱에 발도 카드가 여러 장이면 첫 카드 하나만 혜택을 받아 서로 깎아 먹습니다. 낭인 류파가 약한 이유이기도 합니다(BUG-058).

## 재현 절차
1. 사파 검객으로 전투에 들어가 심법을 먼저 쓰고 「발도술」을 씁니다. 피해가 9가 아니라 4 입니다.
2. 실험: `qa-output/qa-20261127-1430/exp/sim.mjs` 규칙 끄기, 결과 `exp/mech.jsonl`, `exp/mechcard.jsonl`

## 사용자가 정할 것
- **A안 (추천)**: 발도를 "이번 턴 첫 **초식**(공격)"으로 바꿉니다. 심법·행낭 물품은 세지 않습니다.
- "기를 끌어올린 뒤 칼을 뽑는다"는 흐름이 자연스럽고, 플레이어가 순서를 덜 신경 써도 됩니다.
- 발도 카드끼리 깎아 먹는 문제는 남습니다. 그래서 BUG-058 의 낭인 수치는 바꾼 규칙으로 다시 재서 더 작게 잡습니다.
- 이 안은 실험하지 않았습니다. 넣은 뒤 정파 살수·사파 검객·마교 살수를 다시 잽니다.
- **B안**: 규칙은 그대로 둡니다. 낭인 수치만 올립니다(BUG-058, 낭인 강제 판 24.2 → 38.3% 실측).

## 기대 / 실제
- 기대: 정한 규칙대로 발도가 붙고, 카드 풀이와 손패 피해 미리보기도 그 규칙을 따릅니다.
- 실제: 심법·물품을 먼저 써도 발도가 사라집니다.

## 원인 추정
- `src/core/battle.js:497` 발도 판정: `turnCards > 0` 이면 발도가 없습니다.
- `turnCards` 는 `battle.js:685` 에서 초식·심법·물품 모두 셀 때 늘어납니다.
- **주의**: 검기(`battle.js:496`)도 turnCards 를 씁니다. A안은 turnCards 를 바꾸지 말고, 발도 판정용 카운터(예: 이번 턴에 쓴 초식 수)를 따로 둡니다.
