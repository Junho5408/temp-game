# BUG-044 훔치기 무공이 적 기세를 음수까지 깎아 너무 셈
- 상태: 열림
- 심각도: 보통
- 분류: 밸런스
- 발견: qa-20261127-1119 · F-BA-05, F-EX-04

## 증상
훔치기는 적에게 기세가 없어도 매번 적 기세를 n 만큼 깎고, 0 아래로도 내려갑니다. 쓸 때마다 적 공격이 영구로 약해집니다. 연타 적과 두목에게 특히 큽니다.
- 낚아채기+ 6장으로 적 기세가 -12 까지 내려가 대부분의 일반 적 공격(6~12)이 0 이 됐습니다. 기 모으기(+2)로도 거의 회복되지 않습니다(-3 → -1).
- 카드 풀이("적의 기세를 깎고, 적에게 있던 만큼 내 기세로")만 읽으면 적에게 있던 기세를 빼앗는 효과로 보입니다.
- 강제 넣기(사파 기준 45.0%, 단검 1장 40.0%):

| 무공 | 1구역 | 변화 |
|---|---|---|
| 신투 묘수 | 68.2 | +23.2 |
| 날강도 | 63.5 | +18.5 |
| 수법 훔치기 | 62.7 | +17.7 |

- 세 장을 모두 크게 깎으면(1 / 1 / 2) 사파가 38.8 / 43.7 / 44.2 / 43.1 로 무너집니다. 지금 사파의 힘이 훔치기에 크게 기대고 있습니다.
