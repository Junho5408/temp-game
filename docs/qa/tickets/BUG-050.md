# BUG-050 「혈공 장로의 시험」이 마교 권사·살수에게도 검객 무공 『피의 맹세』를 줌
- 상태: 열림
- 심각도: 보통
- 분류: 기능
- 발견: qa-20261127-1430 · F-FN-01, F-EX-04

## 증상
마교 이야기 기연 「혈공 장로의 시험」에서 "피의 단지를 마신다"를 고르면, 어느 계열이든 마교 **검객**(혈검 류파) 희귀 무공 『피의 맹세』(bloodOath)를 얻습니다.
- 마교 권사·살수 덱에 다른 계열 카드가 들어오고, 카드 아래에 "혈검"이 표시됩니다.
- 류파 쏠림(deckSchools)에도 혈검이 섞입니다.
- 8단계 원칙은 "판에 나오는 무공은 내 세력·내 계열만"입니다. 같은 일을 하는 「떨어진 무공서」 기연은 계열로 거릅니다.
- 진행과 자원은 정상입니다.

## 재현 절차
1. 마교 권사(또는 살수)로 출발합니다.
2. 1구역 3층 이후 이야기 기연 「혈공 장로의 시험」에서 "피의 단지를 마신다"를 고릅니다.
3. 덱 끝에 『피의 맹세』가 들어갑니다.
- 규칙만 확인할 때: `createRun({ faction: 'demonic', cls: 'fist' })` → `run.phase = 'event'; run.event = { id: 'cultElder', introDone: true }` → `chooseEventOption(run, 0)`
- 스크립트: `node qa-output/qa-20261127-1430/check-cultelder.mjs`, `node qa-output/qa-20261127-1430/repro-bloodoath.mjs`

## 기대 / 실제
- 기대: 권사·살수 판에서는 같은 계열의 비슷한 무공("피를 내주고 힘을 얻는" 체력 대가 희귀 무공)을 줍니다. 안내 문구도 그 이름으로 나옵니다.
- 실제: 세 계열 모두 `bloodOath(demonic-sword/hyeolgeom)` 입니다. 안내 문구도 늘 "희귀 무공 『피의 맹세』"입니다.

## 원인 추정
- `src/core/events.js:422` `api.addCard('bloodOath')`: 계열을 보지 않습니다. 418줄 근처의 안내 문구(hint)도 고정입니다.
- bloodOath 의 계열은 `src/core/rework-demonic.js:82` 에서 `cls: 'sword', school: 'hyeolgeom'` 입니다.
- 8단계에서 fallenManual(`CARDS[x].cls === run.cls` 로 거름)만 고치고 이 기연의 고정 카드는 남았습니다.

## 제안
계열별 카드 표를 두고, 안내·결과 문구도 그 카드 이름으로 만듭니다.
- 검객: bloodOath 그대로
- 권사: 혈신 `dBloodGod` (혈수 류파)
- 살수: 혈영 폭주 `dBloodRush` (혈영대 류파)

이야기상 일부러 검객 무공을 주는 것이라면, 그 결정을 STORY.md·PROGRESS.md 에 남기고 이 티켓을 닫습니다.

## 완료 조건
- 마교 세 계열로 cultElder 선택지 0을 고르면, 얻은 카드가 `CARDS[id].faction === run.faction && CARDS[id].cls === run.cls` 입니다.
- 안내 문구와 결과 문구에 실제로 얻는 무공 이름이 나옵니다.
- 이를 확인하는 테스트를 추가합니다. 가능하면 모든 기연의 addCard 대상이 run 의 세력·계열과 맞는지 9개 길로 도는 테스트로 넓힙니다.
