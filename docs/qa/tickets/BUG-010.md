# BUG-010 행낭이 가득할 때 약초 노파 금창약을 사면 은자만 나감
- 상태: 열림
- 심각도: 낮음
- 분류: 기능
- 발견: qa-20261126-0921 · F-EX-08

## 증상
행낭 3칸이 가득 찬 상태에서도 약초 노파 기연의 "금창약을 산다" 를 고를 수 있습니다. 고르면 은자 25 만 나가고 물품은 들어오지 않습니다. 결과 문구로 안내는 하지만, 객잔에서는 같은 상황에서 살 수 없게 막아 두어 서로 다릅니다.
같은 종류의 문제가 하나 더 있습니다. 주노의 "한 수 배운다" 는 보물 6개를 모두 가졌을 때도 고를 수 있고, 은자만 받습니다.

## 재현 절차
1. 행낭 3/3, 은자 100 으로 herbSeller 기연에 들어갑니다.
2. "금창약을 산다" 를 고릅니다.
- 도구로 재현: `node qa-output/qa-20261126-0921/extreme.cjs --run=qa-20261126-0921 --only=bagFullAndShop`

## 기대 / 실제
- 기대: 선택지가 꺼져 있습니다 (객잔 canBuy 와 같은 기준).
- 실제: `herbDisabled:false`, 은자 100→75, 행낭은 그대로입니다.

## 원인 추정
- `src/core/events.js:195` `disabled: (run) => run.gold < 25`: 행낭 자리를 보지 않습니다.
- `src/core/events.js:166` (주노): 줄 보물이 남았는지 보지 않습니다 (171행).

## 완료 조건
- 195행 조건에 `|| run.bag.length >= BAG_SIZE` 를 더합니다.
- 166행 조건에 "줄 보물이 없음" 을 더합니다.
- 테스트 추가:
  - 행낭 3/3 인 판에서 금창약 선택이 막히고 은자가 그대로인지 확인합니다.
  - 보물 6개인 판에서 주노 선택지도 같은 방식으로 확인합니다.
