# BUG-061 사파 살수 독문 류파가 약함 (독 터뜨리기 수치)
- 상태: 열림
- 심각도: 낮음
- 분류: 밸런스
- 발견: qa-20261127-1430 · F-BA-07, F-BA-11(독 쥐어짜기)
- 관련: BUG-035 (독 터뜨리기, 수정됨)

## 증상
사파 살수 계열 평균(39.0 / 37.1 / 38.4 / 39.6)은 기준 안입니다. 하지만 류파 차이가 큽니다.
- 류파 강제 판 1구역: 하오문 52.6, 독문 **28.6**(pure 23.1), 함정꾼 30.6.
- 카드 한 장 넣기 1구역: 독 쥐어짜기 **-16.1**%p, 독단지 -7.7, 독 터뜨리기 -6.7.
- 함정꾼은 덫을 먼저 까는 운용이 필요해 봇이 가장 못 쓰는 류파입니다. 사람이 해 본 뒤 정합니다(이 티켓 범위 밖).

## 재현 절차
1. `node tools/qa/balance.mjs --faction=unorthodox --cls=assassin --n=2000 --run=<이름>`
2. 류파 강제: `qa-output/qa-20261127-1430/exp/sim.mjs --school --mode=prefer`

## 기대 / 실제
- 기대: 류파 강제 판 1구역 32~48%.
- 실제: 독문 28.6%.

## 원인 추정 (바꿀 곳)
- 독 터뜨리기 `src/core/cards.js:240` burst 3 (연마 :241 4)
- 독 쥐어짜기 `src/core/cards-unorthodox.js:185` burst 1 (연마 :186 2)

## 제안 (메모리 실험, 2000판)
- 터뜨리기 +1: 독 터뜨리기 3 → 4, 독 쥐어짜기 1 → 2 (연마도 각 +1). 독문 강제 판 28.6 → 37.0%.
- 예상 자연 판: 39.0 / 37.1 / 38.4 / 39.6 → 41.2 / 43.6 / 40.9 / 47.6
- 독문 독 +1(모든 독 카드)은 독문 46.8%, 자연 판 1구역 50.9% 로 너무 셉니다. 권하지 않습니다.
- 하오문(마름쇠·독성추)은 BUG-064 에서 다룹니다.

## 완료 조건
- 사용자가 수치를 승인합니다.
- 사파 살수 2000판을 다시 재서 모든 구역 기준 안, 독문 강제 판 1구역 32~48% 를 확인합니다.
- 독 터뜨리기·독 쥐어짜기의 터뜨리는 양을 확인하는 규칙 테스트를 추가합니다.
