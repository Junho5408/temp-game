# BUG-011 첫 턴 보물(공청석유·천리안) 발동 연출이 없음
- 상태: 열림
- 심각도: 낮음
- 분류: 화면
- 발견: qa-20261126-0921 · F-FN-01

## 증상
공청석유(기세 1)와 천리안(간파 1)은 첫 턴에 효과가 적용되지만, 보물 이름 팝업이 뜨지 않습니다. 그래서 발동했는지 알 수 없습니다. 2턴부터 발동하는 보물은 팝업이 정상적으로 뜹니다.

## 재현 절차
1. 보물에 stoneMilk·farSight 를 넣고 첫 전투에 들어갑니다.
- 도구로 재현: `node qa-output/qa-20261126-0921/extra-checks2.cjs` (Y01)

## 기대 / 실제
- 기대: 1턴 시작에 보물 팝업이 뜹니다.
- 실제: 상태 칩(勢1·見)은 붙지만 `popups []` 입니다.

## 원인 추정
`src/main.js:426–427`: `runBattle` 이 첫 `startPlayerTurn(b)` 뒤 `takeEvents(b)` 로 이벤트를 버립니다. 이 이벤트는 battle.js:162–165 에서 나옵니다. 2턴부터는 main.js:663 에서 재생합니다.

## 완료 조건
- 첫 화면을 그린 뒤 `playEvents(takeEvents(b))` 로 재생합니다. 손패 뽑기 연출과 겹치면 보물·상태 이벤트만 걸러 재생합니다.
- 테스트 추가:
  - 규칙 테스트: stoneMilk 를 가졌을 때 첫 startPlayerTurn 이벤트에 treasure:stoneMilk 가 들어 있는지 확인합니다.
  - smoke 에서는 팝업이 뜨는지 확인합니다.
