# BUG-043 독성추(사파 희귀 무공)가 지나치게 셈
- 상태: 수정됨
- 심각도: 보통
- 분류: 밸런스
- 발견: qa-20261127-1119 · F-BA-04

## 증상
독성추를 시작 덱에 강제로 넣으면 사파 1구역 돌파율이 45.0 → 83.2% (+38.2%p)가 됩니다. 새 무공 130장 중 압도적 1위입니다(2위 신투 묘수 +23.2, 3위 만천화우 +19.2).
- 쓰지 않고 들고만 있어도 턴이 끝날 때 던져져 피해 9와 중독 6이 들어갑니다. 손에 들어오는 턴마다 공짜로 값어치를 냅니다.
- BUG-034(마름쇠)·BUG-035(독 터뜨리기)와는 다른 카드입니다.

## 재현 절차
1. 강제 넣기 실험: `qa-output/qa-20261127-1119/exp/` 의 `sim.mjs` · `worker.mjs` (cards.jsonl, 600판)
2. 비교 기준: 사파 기본 45.0%, 단검 1장 넣기 40.0%.

## 기대 / 실제
- 기대: 희귀 무공 상위권(+15~+25%p) 정도.
- 실제: +38.2%p.

## 원인 추정
- `src/core/cards-unorthodox.js:245-249` `uPoisonHammer`: 피해 10, 던짐 9, 던질 때 중독 6, 연마 `{ damage: 12, thrown: 11 }`.

## 제안
- 피해 10→9, 던짐 9→5, 던질 때 중독 6→2, 연마 `{ damage: 11, thrown: 7 }`.
- 결과: 강제 넣기 66.8% (+21.8%p), 만천화우와 비슷한 희귀 상위권.
- 덜 깎은 안은 아직 셉니다: 던짐 6 / 중독 3 이면 70.2%, 던짐 5 / 중독 4 면 72.2%.
- BUG-044(훔치기 수치안)와 함께 넣은 사파 보통 판: 42.1 / 48.1 / 53.3 / 54.3, 진엔딩 판 최종 48.9.

## 완료 조건
- 사용자가 수치를 승인합니다. BUG-044 와 **함께** 넣습니다.
- 독성추 수치와 설명을 바꿉니다.
- 사파 3000판을 다시 재서 모든 구역 30~60%, 1구역 35~45% 를 확인합니다.
- 독성추를 손에 든 채 턴을 끝내면 피해 5·중독 2가 들어가는지 확인하는 규칙 테스트를 추가합니다.
