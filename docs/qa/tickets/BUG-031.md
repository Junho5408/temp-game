# BUG-031 백리현 등장 장면 동안 상단 체력이 회복 전 값으로 보임
- 상태: 수정됨
- 심각도: 낮음
- 분류: 화면
- 발견: qa-20261127-0536 · F-FN-05

## 증상
귀면을 이긴 뒤 백리현 등장 장면이 나오는 동안 상단 체력이 회복 전 값(예: 20/70)으로 남습니다. 실제 판 체력은 이미 58 로 회복되어 있습니다. 장면이 끝나야 58 로 바뀝니다.

## 재현 절차
1. `node qa-output/qa-20261127-0536/fn/c-true.cjs --faction=unorthodox` 를 돌립니다.
2. 귀면 전투에서 체력 20 으로 이깁니다 → 등장 장면을 봅니다.
- 근거: 스크린샷 `fn/C-unorthodox-04-bridge.png`(상단 20/70), 결과 `fn/c-true-unorthodox-gwimyeon_baekri.json` C-unorthodox-04 의 `php: 58`

## 기대 / 실제
- 기대: 상단 체력이 실제 판 체력과 같거나, 회복되는 순간이 연출로 보입니다.
- 실제: 장면 내내 회복 전 값입니다.

## 원인 추정
- `src/core/run.js:330` 에서 TRUE_BOSS_HEAL 로 run.hp 를 올립니다.
- 상단은 `renderRunInfo()`(`src/main.js:467`)로만 갱신되는데, `src/main.js:329-353` 에서 TRUE_BRIDGE 재생 전에는 이 함수를 부르지 않습니다.
