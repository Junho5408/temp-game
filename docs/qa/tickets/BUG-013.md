# BUG-013 행낭이 가득하면 떨어진 물품을 바꿔 넣을 수 없음
- 상태: 열림
- 심각도: 낮음
- 분류: 기능
- 발견: qa-20261126-0921 · F-FN-03

## 증상
행낭 3칸이 가득 찬 상태에서 전투 보상으로 물품이 떨어지면 "행낭이 가득 찼다" 문구만 나오고 물품은 사라집니다. 기존 물품을 버리고 새것을 챙길 방법이 없습니다.

## 재현 절차
1. 행낭 3칸을 연막탄으로 채웁니다.
2. 일반 전투에서 이겨 물품이 떨어지게 합니다 (extra-checks X07).

## 기대 / 실제
- 기대: 행낭 칸을 눌러 "버리고 챙기기" 를 할 수 있습니다.
- 실제: 문구만 나옵니다.

## 원인 추정
- 보상 화면 `src/ui/screens.js:149` 는 문구만 보여 줍니다.
- `discardItem`(src/core/run.js:196–200)은 있지만 화면에서 쓰지 않습니다.

## 완료 조건
- SPEC 에 규칙이 없으므로 **넣을지 먼저 사용자가 정합니다.**
- 넣기로 하면 core 에 `swapItem(run, index, id)` 를 두고 보상 화면에 연결합니다.
- 테스트 추가: 가득 찬 행낭에서 교체한 뒤 칸이 3개이고 새 물품이 들어 있는지 확인합니다.
