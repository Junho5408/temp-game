# BUG-027 긴 무공 설명이 카드 밖으로 넘치거나 명중 표시에 가려짐
- 상태: 열림
- 심각도: 보통
- 분류: 화면
- 발견: qa-20261127-0536 · F-FN-01

## 증상
6-E 에서 새로 생긴 무공 다수는 설명이 4~5줄입니다. 손패와 보상 화면에서 이 설명이 카드 아래로 넘치거나 명중 표시(명중 90% 등)에 가립니다. 그래서 '입마 +2'·'소멸'·'마기 +1' 처럼 고를 때 꼭 알아야 할 내용이 안 보입니다.
- 측정 결과 131장(연마 전후) 중 44개가 해당합니다. 넘친 높이는 8~28px, 명중 표시와 겹친 높이는 15~48px 입니다.
- 정파는 4종(역류검·일지선·유성낙화·사혈점)이고, 나머지는 대부분 사파·마교 카드입니다.
- 예:
- 마신강림: "입마 +2" 가 잘림
- 천마해체대법+: "소멸" 이 안 보임
- 흡혈 일섬: "마기 +1" 이 카드 밖
- 뒤통수: "약화 시 2배" 가 카드 밖
- 만천화우: "암기 8 · 독 3" 이 가림
- 매수: "소멸" 이 넘침
- 독 터뜨리기: 전투 중 "지금 피해" 줄 때문에 "중독은 사라짐" 이 가림
- 보상 화면의 마기 흡수: "심법 · 일반" 줄이 카드 밖

## 재현 절차
1. `node qa-output/qa-20261127-0536/fn/e2-shot.cjs` 를 돌립니다. 마교 판 손패를 흡혈 일섬·천마해체대법+·뒤통수·만천화우·마신강림으로 만들어 960×540 에서 촬영합니다.
2. 전체 측정은 `node qa-output/qa-20261127-0536/fn/e-cardfit.cjs` 입니다(결과 `fn/E01-cardfit.json`).
- 스크린샷: `fn/E02-long-cards.png`, `fn/E02-crop.png`, `fn/D03-crop.png`, `fn/B08-reward.png`

## 기대 / 실제
- 기대: 모든 카드 설명이 카드 틀 안에 보이고 명중 표시와 겹치지 않습니다.
- 실제: 44개 카드에서 설명 끝줄이 잘리거나 가립니다.

## 원인 추정
- `style.css:181-200`: `.card` 높이가 144px 로 고정입니다.
- `style.css:275-286`: `.card .desc` 에 넘침 처리가 없습니다.
- `style.css:891-907`: `.card .hit` 가 카드 아래 5px 에 절대 위치로 놓여 설명 위에 겹칩니다.
- `src/core/cards.js:410-452` `describe` 가 효과마다 한 줄씩 만듭니다.
- `src/main.js:724-741` `renderHand` 가 줄을 다시 쓰고, 독 터뜨리기에는 줄을 하나 더 붙입니다(740행).

## 완료 조건
- 다음 방법을 하나 또는 여러 개 조합합니다.
- 짧은 줄을 합칩니다(예: "입마 +2 · 소멸").
- 줄이 많은 카드는 글자 크기·줄 간격을 자동으로 줄입니다(예: `.desc.dense`).
- 명중 표시를 설명 영역 밖으로 옮깁니다.
- 독 터뜨리기의 "지금 피해" 줄은 첫 줄을 대체하게 합니다.
- 131장(연마 전후) 모두 손패·보상 화면에서 설명이 카드 틀 안, 명중 표시 위쪽에 들어갑니다. 960×540 과 휴대폰 가로(640×360)에서 모두 확인합니다.
- 이를 확인하는 검사를 smoke 에 추가합니다(`fn/e-cardfit.cjs` 방식). 모든 카드를 손패 크기로 그린 뒤 `.desc` 아래끝이 카드 틀과 `.hit` 위끝 안에 있는지 봅니다.
