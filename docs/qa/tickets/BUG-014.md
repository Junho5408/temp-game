# BUG-014 보물·상태·특성 설명이 마우스 hover 로만 보임 (터치 불가)
- 상태: 수정됨
- 심각도: 낮음
- 분류: 화면
- 발견: qa-20261126-0921 · F-FN-04

## 증상
상단 보물 아이콘, 상태 칩, 적 특성, 행낭 칸의 설명이 마우스를 올렸을 때 뜨는 툴팁(title)에만 들어 있습니다. 터치 기기에서는 설명을 볼 수 없습니다. SPEC 의 "마우스 + 터치 지원" 과 맞지 않습니다.

## 재현 절차
1. 코드를 확인합니다 (실제 터치 기기로는 아직 테스트하지 않았습니다).
   - `src/main.js:401` 보물 칩
   - 497·501 상태 칩
   - 503–504 특성
   - 404 행낭
2. src 전체에 터치·길게 누르기 처리기가 없습니다.

## 기대 / 실제
- 기대: 탭이나 길게 누르기로 설명을 볼 수 있습니다.
- 실제: hover 로만 보입니다.

## 원인 추정
위 줄들이 `title` 속성만 씁니다.

## 완료 조건
- 탭·길게 누르기로 여는 공통 툴팁(설명은 data 속성에 두고, 떠 있는 상자 하나로 보여 줌)을 만듭니다. 모바일 단계에서 BUG-007 과 함께 처리합니다.
- 테스트 추가: Playwright 터치 모드에서 보물 칩을 탭하면 설명 글이 보이는지 확인합니다.

## 처리 기록
