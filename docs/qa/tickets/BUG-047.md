# BUG-047 보물 설명의 "약화 1"이 실제로는 흐트러짐
- 상태: 수정됨
- 심각도: 낮음
- 분류: 화면
- 발견: qa-20261127-1119 · F-EX-07

## 증상
보물 세 개의 설명이 "약화 1"이라고 쓰지만 실제로는 흐트러짐(亂)을 겁니다. 게임에서 "약화"는 "흐트러짐·중독·굳음 중 하나라도 걸린 상태"라는 조건 이름으로 쓰여서 헷갈립니다.
- 호신부: "전투 첫 턴에 적에게 약화 1"
- 음풍 비결: "첫 턴 적 약화 1, 약화·중독 적에 한 타 +2" (한 문장에서 상태 이름과 조건 두 뜻으로 섞어 씀)
- 귀왕 비도갑: "매 턴 적에게 약화 1"

## 재현 절차
1. `src/core/items.js:153`(호신부), `:253`(음풍 비결), `:261`(귀왕 비도갑)의 설명과 fx 를 봅니다. fx 는 모두 `weak` 입니다.
2. 전투에서 호신부를 가지고 들어가면 적에게 흐트러짐 1이 붙습니다.

## 기대 / 실제
- 기대: 상태 이름이 화면 용어(weak = 흐트러짐)와 같습니다.
- 실제: "약화"라고 씁니다.

## 원인 추정
- 화면 용어는 `src/main.js:42/882` 에서 weak = "흐트러짐"입니다.
- "약화" 조건은 `src/core/cards.js:491`, 실제 판정은 battle.js:508 `isDebuffed` 입니다.

## 완료 조건
- 세 설명의 "약화 1"을 "흐트러짐 1"로 바꿉니다.
- 음풍 비결은 "첫 턴 적 흐트러짐 1, 약화(흐트러짐·중독·굳음)된 적에 한 타 +2"처럼 씁니다. 실제 조건(`isDebuffed`)에 굳음이 들어가는지 함께 확인해 문구를 맞춥니다.
- 이를 확인하는 규칙 테스트를 추가합니다(TREASURES 설명에 "약화 1"처럼 숫자가 붙은 "약화"가 없음).
