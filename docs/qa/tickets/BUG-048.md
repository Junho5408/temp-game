# BUG-048 체력 대가 무공(혈검 등)에 마기가 쌓인다는 풀이가 없음
- 상태: 열림
- 심각도: 낮음
- 분류: 화면
- 발견: qa-20261127-1119 · F-FN-01

## 증상
마교 무공 중 체력을 대가로 쓰는 카드(혈검 등)는 쓰면 마기 +1(혈해 상태면 +3)이 쌓입니다. 그런데 카드 툴팁에 이 풀이가 없습니다. 혈검 카드의 툴팁은 빈 문자열입니다. 마기 칩 툴팁에만 "체력을 대가로 쓰면 쌓인다"가 있습니다.

## 재현 절차
1. 마교 판에서 전투를 시작하고 손패의 혈검(체력 -3, 피해 12)에 마우스를 올립니다.
2. 또는 `node qa-output/qa-20261127-1119/ui-check.cjs` 의 C 결과: `{"id":"bloodSword","desc":"피해 12\n체력 -3","title":""}` (`ui/result.json`).

## 기대 / 실제
- 기대: 체력 대가 마교 무공의 툴팁에 "마기: 체력을 대가로 쓰면 +1" 같은 풀이가 나옵니다.
- 실제: 풀이가 없습니다.

## 원인 추정
- `src/core/cards.js:494` cardKeywords 의 마기 풀이 조건이 `c.magi || c.magiSpend || c.purge || c.bloodSea || c.magiDouble` 이고 `hpCost` 가 없습니다.
- 실제 규칙은 `src/core/battle.js:550-553` 입니다.

## 완료 조건
- 마교(faction 'demonic') 카드 중 hpCost 가 있는 카드는 툴팁에 마기 풀이가 나옵니다. 정파·사파에는 마기가 없으므로 넣지 않습니다. 마교가 아닌 hpCost 카드가 있는지도 확인합니다.
- 이를 확인하는 규칙 테스트를 추가합니다(hpCost 가 있는 마교 카드는 모두 cardKeywords 에 "마기"가 들어 있음).
