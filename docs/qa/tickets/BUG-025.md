# BUG-025 승리 화면 "이(가)/을(를)" 표기, 같은 물품 칸과 바꿔 넣으면 기회만 사라짐
- 상태: 수정됨
- 심각도: 낮음
- 분류: 기능
- 발견: qa-20261127-0035 · F-FN-03 (+ F-BA-09 메모)
- 관련: BUG-013 후속, BUG-012 후속(restHeal 정리)

## 증상
행낭이 가득할 때 물품이 떨어지면 승리 화면에 두 가지 문제가 있습니다.
1. 문구가 "금창약이(가) 있었지만 행낭이 가득 찼다", "행낭에 금창약을(를) 챙겼다" 로 나옵니다.
2. 바꿔 넣기 버튼에 떨어진 것과 같은 물품 칸(예: 금창약)도 나옵니다. 누르면 행낭은 그대로인데 바꿔 넣기 기회만 사라집니다.

## 재현 절차
1. 행낭 3칸을 `[금창약, 해독산, 연막탄]` 으로 채웁니다.
2. 일반 전투에서 금창약이 떨어지게 해서 이깁니다(`fn-checks.cjs` S6, run.rng 0.01 고정).
3. 문구를 보고, "瘡 금창약" 칸 버튼을 누릅니다.
- core 만 확인: `node qa-output/qa-20261127-0035/repro-swap-same.mjs`
  - 결과: `{"before":["geumchang","antidote","smoke"],"ok":true,"after":["geumchang","antidote","smoke"],"itemKept":true,"again":false}`
- 스크린샷: `qa-output/qa-20261127-0035/fn/S6-bag-swap.png`

## 기대 / 실제
- 기대: "금창약이 있었지만", "금창약을 챙겼다" 처럼 조사가 자연스럽습니다. 같은 물품 칸은 버튼에서 빠지거나 흐리게 보이고, 눌러도 기회가 사라지지 않습니다.
- 실제: 조사가 "(가)/(를)" 로 고정이고, 같은 물품끼리 바꿔도 itemKept 가 true 가 됩니다.

## 원인 추정
- `src/ui/screens.js:147-150`: 조사를 고정 문자열로 씁니다.
- 같은 표기가 다른 곳에도 있습니다: `src/main.js:885` (파기 배너 "이(가) 끊겼다"), `src/core/events.js:61, 175, 228, 274`.
- `src/ui/screens.js:158-161`: 행낭의 모든 칸을 버튼으로 만들고 같은 물품도 거르지 않습니다.
- `src/core/run.js:388-395` `swapRewardItem()`: `run.bag[bagIndex] === r.item` 인지 확인하지 않습니다.

## 완료 조건
- 받침 유무로 이/가, 을/를 을 고르는 도움 함수를 하나 두고 위 6곳에서 씁니다(한글 음절 `(code-0xAC00)%28` 로 판단, 또는 물품 데이터에 조사를 넣기).
- 화면에서 같은 물품 칸 버튼은 빠지거나 비활성입니다.
- core 의 `swapRewardItem` 은 같은 물품 칸이면 false 를 돌려주고 itemKept 를 바꾸지 않습니다(규칙은 core 에).
- 함께 정리 (BUG-012 후속, F-BA-09 메모): core 의 `restHeal`(`src/core/run.js:402-408`)은 체력이 가득해도 진행됩니다. 지금은 화면(screens.js 의 `canRestHeal`)에서만 막고 있습니다. `restHeal` 안에서도 `canRestHeal` 을 확인해 체력이 가득하면 아무것도 바꾸지 않고 false 를 돌려주게 합니다.
- 테스트를 추가합니다.
  - `swapRewardItem` 을 같은 물품 칸에 쓰면 false 이고 itemKept 가 false 로 남습니다.
  - 조사 도움 함수: 받침 있는 이름(금창약 → 이/을, 연막탄)과 받침 없는 이름 하나.
  - 체력이 가득할 때 `restHeal` 을 부르면 체력·판 상태가 바뀌지 않습니다.
