# BUG-003 세력 선택 화면에서 새로고침하면 회차가 늘어 기억 슬롯이 공짜로 열림
- 상태: 수정됨
- 심각도: 높음
- 분류: 저장
- 발견: qa-20261126-0921 · F-EX-01

## 증상
세력 선택 화면에서 새로고침할 때마다 "N번째 생" 이 1씩 늘어납니다. 기억 슬롯 수는 `1 + floor(회차/3)` 이므로, 판을 시작하지도 않고 "들고 갈 기억" 이 1개에서 3개까지 열립니다.

## 재현 절차
1. 프롤로그를 마친 기록(runs 2, 진행 중인 판 없음)으로 시작합니다.
2. "다시 백 일 전으로" 를 누르고 깨어나는 대사를 넘깁니다.
3. 세력 선택 화면에서 새로고침합니다.
4. 2~3을 반복합니다.
- 도구로 재현: `node qa-output/qa-20261126-0921/extreme.cjs --run=qa-20261126-0921 --only=reloadSelect`

## 기대 / 실제
- 기대: 세력을 골라 판을 실제로 시작할 때만 회차가 1 늘어납니다.
- 실제: runs 가 2→3→4→5→6→7 로 늘고, "들고 갈 기억 3개까지" 가 표시됩니다.

## 원인 추정
`src/main.js:205–208`: `beginLife()` 가 세력 선택 **전에** `startNewRun(meta)`(meta.js:69–71, runs+1)와 `saveMeta()` 를 부릅니다. 판은 그 뒤 renderSelect 콜백(main.js:217–223)에서 만들어집니다.

## 완료 조건
- 회차 증가와 저장을 세력 선택이 확정되는 곳(createRun 직전)으로 옮깁니다.
- 깨어나는 대사(`wakeLines`, main.js:215)와 슬롯 표시(flow.js:100)는 "이번 판 번호"(runs+1)를 쓰도록 맞춥니다.
- 세력 선택에서 새로고침을 몇 번 해도 runs 가 그대로여야 합니다.
- 테스트 추가:
  - core 에 판 시작 확정 함수(예: `beginRun`)를 둡니다. 한 번 부르면 정확히 +1 인지, 선택 전 상태를 저장하고 다시 읽어도 그대로인지 확인합니다.
  - smoke 에 "세력 선택에서 새로고침 후 runs 그대로" 단계를 추가합니다.
