# BUG-057 정파 권사 최종 69.5% (점혈로 귀면을 너무 쉽게 굳힘)
- 상태: 열림
- 심각도: 보통
- 분류: 밸런스
- 발견: qa-20261127-1430 · F-BA-08

## 증상
정파 권사의 최종 구역 돌파율이 69.5% 로 기준(60) 위입니다. 진엔딩 판에서도 70.8% 입니다.
- 원인은 점혈입니다(시작 덱 견제장 ×3, 정파 권사는 점혈 카드 12장).
- 귀면은 2단계 필살기 "귀면멸살 40"이 있는데, 점혈로 굳히면 이 한 방이 통째로 사라집니다.
- 규칙을 끈 실험(같은 2000판)

| 조건 | 1구역 / 2 / 3 / 최종 |
|---|---|
| 지금 | 42.8 / 37.6 / 59.0 / 69.5 |
| 점혈 0 | 36.2 / 33.3 / 51.5 / **55.6** |
| 호신 0 | 34.4 / 36.6 / 57.5 / 69.7 |
| 반격 0 | 41.1 / 38.9 / 59.4 / 66.8 |

- 팔괘 강제 판은 1구역 30.7% 인데 최종은 67.0% 입니다. 정파 살수도 점혈을 끄면 최종이 56.3 → 49.7% 가 됩니다.

## 재현 절차
1. `node tools/qa/balance.mjs --faction=orthodox --cls=fist --n=2000 --run=<이름>`
2. 실험: `qa-output/qa-20261127-1430/exp/sim.mjs --gwPoint=34`

## 기대 / 실제
- 기대: 최종 30~60%.
- 실제: 69.5% (진엔딩 판 70.8%).

## 원인 추정
- `src/core/enemies.js:26` `POINT_MAX = {…, boss: 20}`: 두목은 모두 20 입니다. 적마다 따로 정할 수 없습니다.
- `src/core/battle.js:143` `pointMax: POINT_MAX[def.tier]`
- 굳을 때마다 늘어나는 폭은 `battle.js:63` POINT_STEP = 6.
- 귀면 정의는 `enemies.js:295-297`.

## 제안
- 적 정의에 `pointMax` 칸을 새로 두고, battle.js:143 에서 그 값을 먼저 씁니다. 귀면만 34 로 올립니다.

| 길 | 최종 (지금 → 34) |
|---|---|
| 정파 권사 | 69.5 → **59.5** (28일 때 65.3) |
| 정파 살수 | 56.3 → 50.4 |
| 정파 검객 | 거의 그대로 |

- 1~3구역은 바뀌지 않습니다.
- 선택: 팔괘 공격 카드 피해 +1 이면 팔괘 1구역이 30.7 → 37.5% 가 됩니다. 다만 정파 권사 자연 판 1구역이 45.9% 로 기준 위 경계가 되므로, 넣을지는 사용자가 정합니다.

## 완료 조건
- 사용자가 수치를 승인합니다.
- 귀면 점혈 게이지가 34 로 시작하는지 확인하는 규칙 테스트를 추가합니다. 다른 두목은 20 그대로인지도 함께 봅니다.
- 정파 세 계열 2000판과 정파 진엔딩 판을 다시 재서 정파 권사 최종 60% 이하, 다른 구역 변화 없음을 확인합니다.
