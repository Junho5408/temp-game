# BUG-001 이긴 뒤 대사 중 새로고침하면 이긴 전투를 다시 싸움
- 상태: 수정됨
- 심각도: 높음
- 분류: 저장
- 발견: qa-20261126-0921 · F-EX-05

## 증상
전투에서 이긴 뒤 나오는 대사(예: "쓰러진 복면객의 가면이…") 중에 새로고침하고 이어하면, 같은 고수와 처음부터 다시 싸웁니다. 단서도 아직 얻지 못한 상태가 됩니다. 재전투에서 지면 이미 이긴 판을 잃습니다.

## 재현 절차
1. 복면객(masked) 전투 단계로 판을 저장합니다.
2. 적 체력을 1로 만들고 이깁니다.
3. 승리 대사 중에 새로고침합니다.
4. 이어하기를 누릅니다.
- 도구로 재현: `node qa-output/qa-20261126-0921/extreme2.cjs --run=qa-20261126-0921` (outroReload)

## 기대 / 실제
- 기대: 승리가 확정되어 보상 화면으로 가고, 단서(mask)가 저장되어 있습니다.
- 실제: 저장이 phase 'battle' 로 남습니다. 복면객 등장 대사부터 다시 시작하고, `clues: []` 입니다.

## 원인 추정
`src/main.js:292–299`: 승리 대사(293–296)를 `finishBattle(run, b)`(297) **전에** 재생합니다. 판 저장은 대사가 끝난 뒤 `show()` 에서야 이루어집니다.

## 완료 조건
- 순서를 바꿉니다: `finishBattle` → `collectClues` → `saveRun` → 대사 → `show()`.
- 승리 대사 중 새로고침 → 이어하기를 하면 보상 화면이 나오고 단서가 남아 있어야 합니다.
- 테스트 추가:
  - 규칙 테스트: `finishBattle` 뒤 serializeRun→parseRun 한 판의 phase 가 'battle' 이 아니고 단서가 들어 있는지 확인합니다.
  - smoke 에 "승리 대사 중 새로고침 → 보상 화면" 단계를 추가합니다.
