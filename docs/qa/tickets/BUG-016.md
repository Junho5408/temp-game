# BUG-016 3구역 고수 혈랑 사망률이 높음 (42~44%)
- 상태: 열림
- 심각도: 낮음
- 분류: 밸런스
- 발견: qa-20261126-0921 · F-BA-02

## 증상
3구역 고수 혈랑을 만났을 때 사망률이 42.1% (600판, 38전), 4000판에서는 44.2% (217전) 입니다. 고수 기준 35% 를 넘습니다. 같은 구역 고수 천마검귀는 27.3% 입니다.

## 재현 절차
1. `node tools/qa/balance.mjs --n=600 --run=qa-20261126-0921` 를 돌립니다.
2. 4000판은 `node qa-output/qa-20261126-0921/experiments/run3.mjs base` 로 돌립니다.

## 기대 / 실제
- 기대: 사망률 35% 이하
- 실제: 42~44%
- 수치를 바꿔 본 실험 (시드 1~4000):
  | 변경 | 사망률 |
  |---|---|
  | **체력 110→95** | **34.6%** (3구역 돌파율 +0.7%p) |
  | 살기 제거 | 41.9% |
  | 필살 하향 | 44.7% |
  | 연참 하향 | 43.3% |

## 원인 추정
`src/core/enemies.js:249` `maxHp: 110` 에 회피 20% 가 더해져 전투가 길어집니다. 근거: `experiments/r3a.txt`, `r3b.txt`.

## 완료 조건
- **수치 변경은 적용 전에 사용자 승인이 필요합니다.** 사용자가 "후반은 어렵게" 를 원했으므로 그대로 둘 수도 있습니다.
- 바꾸기로 하면 체력 110→95 로 하고 다시 잽니다. 사망률이 약 35% 이하이고 3구역 돌파율이 30~60% 안이면 닫습니다.
- 그대로 두기로 하면 이유를 PROGRESS.md 에 적고 "보류" 로 닫습니다.
