# BUG-058 사파 검객 1구역 34.2% (흑도·낭인 류파가 약함)
- 상태: 수정됨
- 심각도: 보통
- 분류: 밸런스
- 발견: qa-20261127-1430 · F-BA-05

## 증상
사파 검객 1구역이 34.2%(±1.1) 로, 9개 길 가운데 유일하게 1구역 기준(35~45) 아래입니다.
- 류파 강제 판 1구역: 흑도 **23.4**(pure 13.9), 낭인 **24.2**(pure 17.9), 녹림 45.6.
- 흑도 일반 카드는 한 장 넣으면 -6 ~ -7%p 입니다(흙탕 베기, 칼끝 흔들기, 힘줄 끊기, 독기 서린 도).
- 낭인은 류파 12장 중 6장이 발도 카드입니다. 그런데 발도는 턴의 첫 카드 한 장에만 붙어서 서로 혜택을 깎아 먹습니다(BUG-063). 낭인 강제 판에서 발도를 꺼도 24.2 → 21.4% 로 2.8%p 밖에 안 떨어집니다.
- 참고: 밸런스 봇이 발도 카드를 덜 고르는 편향이 있습니다(보고서 "도구 문제"). 사람 기준에서는 조금 더 높을 수 있습니다.

## 재현 절차

2. 류파 강제: `qa-output/qa-20261127-1430/exp/sim.mjs --school --mode=prefer`

- 기대: 1구역 35~45%, 류파 강제 판 1구역 32~48%.
- 실제: 34.2%, 흑도 23.4 / 낭인 24.2.

## 원인 추정 (바꿀 곳)
- 흑도 dirtyBonus·피해
- `src/core/cards-unorthodox.js:180` 독 묻힌 칼, `:209` 힘줄 끊기

- 규칙은 `battle.js:493`

## 제안 (메모리 실험, 2000판)
- 흑도: dirtyBonus +2, 피해 +1 (dirty 카드 포함). 흑도 강제 판 23.4 → 32.6%
- 낭인: 공격 카드 피해 +3, 발도 +2 (예: 발도 4 / 발도 5 → 7 / 발도 7). 낭인 강제 판 24.2 → 38.3%. 피해 +2만 하면 27.7% 로 부족합니다.
- 둘 다 넣은 사파 검객 자연 판: 34.2 / 39.8 / 44.1 / 47.5 → **41.9 / 44.2 / 44.3 / 47.6**. 진엔딩 판 42.5 / 47.8 / 46.8 / 42.1.
- **순서**: BUG-063 에서 발도 규칙을 "첫 초식"으로 바꾸기로 하면, 낭인 수치는 그 규칙으로 다시 재서 더 작게 잡습니다.

## 완료 조건
- 사용자가 수치를 승인합니다. BUG-063 결정이 먼저입니다.
- 사파 검객 2000판과 사파 진엔딩 판을 다시 재서 1구역 35~45%, 나머지 30~60%, 흑도·낭인 강제 판 1구역 32~48% 를 확인합니다.
- 바뀐 카드 값(예: 발도술 발도 수치)을 확인하는 규칙 테스트를 추가합니다.
