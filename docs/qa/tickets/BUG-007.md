# BUG-007 작은 세로 화면에서 버튼이 너무 작아짐
- 상태: 열림
- 심각도: 보통
- 분류: 화면
- 발견: qa-20261126-0921 · F-EX-07

## 증상
휴대폰 세로 화면(360×640, 320×480)에서는 가로 비율 무대가 통째로 줄어듭니다. 그래서 턴 종료 버튼과 카드가 손가락으로 누르기 어려울 만큼 작아집니다. 가려지는 버튼은 없습니다. 지금은 데스크톱이 대상이므로 모바일 단계 전에 처리하면 됩니다.

## 재현 절차
1. 개발자 도구에서 화면을 360×640 으로 두고 전투 화면을 봅니다.
- 도구로 재현: `node qa-output/qa-20261126-0921/extreme.cjs --run=qa-20261126-0921 --only=viewports`

## 기대 / 실제
- 기대: 누르는 대상이 약 40px 이상이거나, "가로로 돌려 주세요" 안내가 나옵니다.
- 실제:
  - 360×640: 무대 높이 203px, 턴 종료 버튼 42×19px, 카드 폭 40px
  - 320×480: 턴 종료 37×17px
  - 640×360 가로 화면은 75×33px 로 쓸 만합니다.

## 원인 추정
`src/main.js:105–108` `fit()`: 960×540 비율 그대로 축소합니다. 세로 화면 안내나 세로 배치가 없습니다.

## 완료 조건
- 짧게는 세로이고 폭이 좁을 때 회전 안내를 띄웁니다. 길게는 세로 전용 배치를 만듭니다. 어느 쪽으로 할지는 모바일 단계에서 사용자가 정합니다 (BUG-014 와 함께).
- 테스트 추가: viewports 점검을 smoke 에 넣고, "주요 버튼 40px 이상 또는 회전 안내가 보임" 을 통과 조건으로 합니다.
