# BUG-006 덱 보기 창이 열려 있어도 키보드로 카드 사용·턴 종료가 됨
- 상태: 수정됨
- 심각도: 보통
- 분류: 기능
- 발견: qa-20261126-0921 · F-EX-06

## 증상
전투 중 "덱 N" 창을 열어 둔 채 숫자키(1~9)나 E 를 누르면, 창 뒤에서 카드가 쓰이고 턴이 넘어갑니다. 적의 공격 연출은 창에 가려 보이지 않은 채로 맞습니다.

## 재현 절차
1. 전투 중 상단 "덱 N" 버튼을 누릅니다.
2. `1` 을 누르고, 이어서 `e` 를 누릅니다.
- 도구로 재현: `extreme2.cjs` (deckModalKeyboard)

## 기대 / 실제
- 기대: 창이 열려 있으면 전투 입력이 막힙니다 (Esc 로는 창을 닫음).
- 실제: 내공 3→2, 손패 5→4, 턴 1→2 가 됩니다.

## 원인 추정
`src/main.js:674–675`: 키보드 처리기가 화면이 전투인지만 확인합니다. `openDeck`(src/ui/screens.js:279–281)은 창을 보이게만 하고 화면 상태는 그대로 둡니다.

## 완료 조건
- 덱 창이 열려 있으면 키 입력을 막고 Esc 로 창을 닫게 합니다. 대사·패널 오버레이에도 쓸 수 있는 공통 확인(예: `inputBlocked()`)을 두면 좋습니다.
- 테스트 추가: smoke 에 "덱 창을 열고 1·E 를 누름 → 내공·턴 그대로" 단계를 넣습니다.
