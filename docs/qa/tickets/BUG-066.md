# BUG-066 기억한 무공을 다른 세력·계열 판에 가져가는 것 정리 (사용자가 정할 것)
- 상태: 열림
- 심각도: 낮음
- 분류: 기능
- 발견: qa-20261127-1430 · F-FN-04

## 증상
회귀 때 기억한 무공은 세력·계열과 상관없이 아무 판에나 들고 출발할 수 있습니다. 예를 들어 마교 권사 판에서 기억한 무공을 정파 검객 판에 가져갑니다.
- 이것은 버그가 아니라 PROGRESS.md 278줄의 결정("회귀의 '기억한 무공'은 세력과 상관없이 가져갈 수 있게 둠")대로입니다.
- 다만 8단계에서 "판에 나오는 무공은 내 세력·계열만" 원칙이 생겼습니다. 기억 무공만 예외인지 정해 두지 않았습니다.
- 지금 화면에는 다른 계열 무공이라는 표시가 없습니다.
- 다른 계열 기억 카드는 류파 쏠림(deckSchools)에 들어갑니다. 하지만 그 류파 카드가 이 판의 풀에 없어서 실제 효과는 없습니다.

## 재현 절차
1. 마교 권사 판에서 쓰러져 무공 하나를 기억합니다.
2. 정파 검객 칸을 고르고 기억 칸에서 그 무공을 고릅니다.
3. 출발 덱에 들어갑니다. (탐색 QA 극단 상황 "memoryCross", 스크린샷 `ex-memoryCross-select.png`)

## 사용자가 정할 것
- **A안 (추천)**: 지금처럼 어느 판에나 가져가게 둡니다.
- 회귀물에서 "전생의 기억을 이어받는" 재미이고, 이미 정한 결정과 맞습니다.
- 기억 칸의 카드에 "다른 계열"(또는 "다른 세력") 표시를 붙여 플레이어가 알고 고르게 합니다.
- PROGRESS.md 에 "8단계 뒤에도 기억 무공은 계열 원칙의 예외"라고 한 줄 남깁니다.
- **B안**: 같은 세력·계열 판에서만 고를 수 있게 막습니다. 다른 칸을 고르면 그 기억 무공은 흐리게 보이고 고를 수 없습니다.

## 기대 / 실제
- 기대: 정한 범위대로 동작하고, 화면에서도 알 수 있습니다.
- 실제: 범위 결정이 8단계 뒤 다시 확인되지 않았고, 화면 표시가 없습니다.

## 원인 추정
- `src/core/meta.js:157-160` validateLoadout: 세력·계열을 보지 않습니다.
- `src/ui/flow.js:166-175` 선택 화면 기억 칸: 고른 칸과 상관없이 meta.memories 를 모두 보여 줍니다.

## 완료 조건
- 사용자가 A안 또는 B안을 고르고 PROGRESS.md 에 적습니다.
- A안: 다른 계열 기억 카드에 표시가 뜨는지 화면에서 확인합니다.
- B안: 다른 칸에서는 그 기억 무공을 고를 수 없고, validateLoadout 이 거르는지 확인하는 테스트를 추가합니다.
