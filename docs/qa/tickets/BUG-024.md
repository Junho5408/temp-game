# BUG-024 휴대폰 가로 화면에서 音·덱 버튼과 행낭 칸이 너무 작음
- 상태: 열림
- 심각도: 낮음
- 분류: 화면
- 발견: qa-20261127-0035 · F-FN-02
- 관련: BUG-007 (그때 완료 조건 "주요 버튼 40px 이상"은 세로 화면만 다뤘음)

## 증상
휴대폰 가로 화면에서는 게임 화면 전체가 줄어들어 위쪽 막대의 音·덱 버튼과 행낭 칸이 손가락으로 누르기 어려울 만큼 작아집니다. 동작은 정상입니다. 턴 종료 버튼과 카드는 쓸 만한 크기입니다.

| 화면 | 音 버튼 | 덱 버튼 | 행낭 칸 |
|---|---|---|---|
| 844×390 | 20×20 | 40×20 | 32×33 |
| 640×360 | 19×19 | 37×19 | 29×31 |
| 568×320 | 17×17 | 32×17 | 26×27 |

## 재현 절차
1. `node qa-output/qa-20261127-0035/fn-checks3.cjs` 를 실행하고 전투 화면에서 크기를 잽니다(U2).
- 근거: `qa-output/qa-20261127-0035/fn/result3.json` U2, 스크린샷 `qa-output/qa-20261127-0035/fn/U2-568x320-battle.png`

## 기대 / 실제
- 기대: 터치로 누르는 버튼이 화면 기준 약 40px 이상입니다.
- 실제: 17~33px 입니다.

## 원인 추정
- `src/main.js` 의 `fit()` 은 960×540 무대 전체를 같은 비율로 줄입니다(844×390 에서 약 0.72배).
- `style.css:1034-1041` `#sound-button` 28×28, `style.css:388-` `#deck-button` 은 padding 3px(높이 약 26), `style.css:974` 행낭 칸 44×46 으로 무대 기준 크기가 고정되어 있습니다.

## 완료 조건
- 터치 모드(coarse pointer)에서 音·덱 버튼과 행낭 칸이 844×390 기준 40px 안팎이 됩니다. 방법은 둘 중 하나입니다.
  - 무대 기준 크기를 키웁니다(音 약 44, 덱 높이 약 40).
  - 보이는 크기는 두고 투명한 누름 영역만 넓힙니다.
- smoke 의 viewports 점검에 가로 568×320·640×360·844×390 을 추가합니다. 터치 모드에서 `#sound-button`·`#deck-button`·`#end-turn`·`.bag-slot` 의 크기가 정한 기준 이상인지 확인합니다.
