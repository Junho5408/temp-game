# BUG-040 훔치기로 적 기세가 음수가 되면 "기세 +-2"로 뜨고 적 상태 칸에 안 보임
- 상태: 수정됨
- 심각도: 보통
- 분류: 화면
- 발견: qa-20261127-1119 · F-EX-02

## 증상
사파 훔치기 무공(낚아채기·날강도·신투 묘수 등)을 기세 0인 적에게 쓰면:
- 떠오르는 글자가 "기세 +-2"처럼 나옵니다.
- 적이 강해지는 연출(강화 동작)이 나옵니다.
- 적 기세가 -12 까지 내려가도 적 상태 칸에는 아무것도 보이지 않습니다. 적 의도 숫자에만 깎인 피해가 반영됩니다.

## 재현 절차
1. `node qa-output/qa-20261127-1119/ex-ui.cjs S1` 을 돌립니다. 사파로 출발해 첫 전투 덱을 낚아채기+ 5장과 신투 묘수 5장으로 바꾸고 카드 6장을 씁니다.
2. 결과 `ex-ui-S1.json`: 떠오르는 글자 "기세 +-2" 6번, 상태 `{"eStr":-12,"enemyChips":""}`.
3. 손으로 할 때: 사파 전투에서 기세 0인 적에게 낚아채기를 한 장 씁니다. "기세 +-1"이 뜨고 적 상태 칸이 비어 있습니다.
- 스크린샷: `qa-output/qa-20261127-1119/ui-S1-steal.png`

## 기대 / 실제
- 기대: "기세 -2"처럼 부호가 맞게 뜨고, 약해지는 연출(또는 연출 없음)이 나옵니다. 적 상태 칸에 음수 기세가 보입니다.
- 실제: "기세 +-2", 강화 연출, 상태 칸에 안 보임.

## 원인 추정
- `src/core/battle.js:644-650` `playCard` 의 steal 이 `{ type:'status', kind:'strength', amount: -c.steal }` 을 보냅니다.
- `src/main.js:1064`: strength 이벤트면 부호와 상관없이 `scene.buff` 를 부릅니다.
- `src/main.js:1065`: strength·evasion·point 에 늘 `'+'` 를 붙여 "+-2"가 됩니다.
- `src/main.js:633` `renderUnit` 의 상태 칩 조건 `v > 0` 때문에 음수 기세가 숨습니다.
- 기세는 늘 0 이상이라고 가정한 화면 코드에, 훔치기가 처음으로 음수 기세를 만들었습니다.

## 완료 조건
- 떠오르는 글자에 "+-"가 나오지 않습니다. 음수면 "기세 -2"처럼 나옵니다.
- 음수 기세 변화에는 강화 연출이 나오지 않습니다.
- 적 기세가 음수면 상태 칸에 다른 색으로 "勢-12" 처럼 보이고, 툴팁에 "공격 피해 -12" 가 뜹니다. (BUG-044 에서 "0 아래로 안 내려감" 규칙을 고르면 이 항목은 필요 없지만, 글자 부호는 그래도 고칩니다.)
- 이를 확인하는 검사를 추가합니다. smoke: 사파 전투에서 낚아채기를 쓴 뒤 팝업에 "+-"가 없고 `#enemy-info .statuses` 가 음수 기세를 보여 주는지 봅니다. 규칙 테스트: steal 이벤트의 amount 부호를 확인합니다.
