## 제안 (메모리 실험, 같은 시드 2000판)
1. 독혈 흡혈 0.5 → 0.4, 고혈참 0.75 → 0.6
2. 혈영대 체력 대가 -2 (최소 1)
3. 혈수 체력 대가 -2 (최소 1), 혈계 +1

| 비교 | 1구역 / 2 / 3 / 최종 |
|---|---|
| 마교 살수 자연 판 (지금 → 1+2) | 39.8 / 52.6 / 63.7 / 40.4 → **42.8 / 51.3 / 56.9 / 36.8** |
| 독혈 강제 판 (1구역) | 58.7 → 52.6 |
| 혈영대 강제 판 (1구역, 2만) | 27.5 → 36.9 |
| 혈수 강제 판 (3) | 19.3 → **36.4** / 42.0 / 44.1 / 24.4 |
| 마교 권사 자연 판 (지금 → 3) | 40.4 / 37.0 / 46.5 / 33.1 → 39.1 / 40.3 / 43.2 / **24.3** |
| 진엔딩 마교 살수 최종 (1+2) | 25.2 → 26.1 |

- **남는 문제**: 마교 권사 최종이 24.3% 로 기준 아래가 됩니다(n=136, ±3.7). 마교 최종을 받쳐 줄 조정이 필요합니다.
- 밸런스 QA 후보: 마교 판에서만 귀면 체력 235 → 220 (실험하지 않음)
- **주의**: BUG-042 때 "마교 길에서만 귀면 체력을 낮추는 안"은 거의 효과가 없었습니다(215: 23.2%, 200: 25.3%). 그래서 귀면 체력 말고 다른 안(예: 마교 권사 혈수 보강을 -1 로 줄이고 다른 곳을 보강)도 함께 재야 합니다.
- 독혈을 더 내리는 안(0.3 / 0.5)은 독혈 47.5% 가 되지만 마교 살수 최종이 28.9% 로 떨어져 권하지 않습니다.
- 혈수 약한 안(체력 대가 -1, 혈계 +1)은 혈수 32.1% 로 부족했습니다.
