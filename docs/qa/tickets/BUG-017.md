# BUG-017 2·3구역 일반 적 일부가 너무 약함

- 심각도: 낮음
- 분류: 밸런스

## 증상
아래 일반 적들은 평균 피해 5~6, 약 3턴이면 쓰러집니다. 1구역 일반 적(평균 피해 8.5~17)보다 약합니다. "위 구역일수록 어렵게" 와 맞지 않습니다.

| 적 | 구역 | 평균 피해 (600판 / 4000판) |
|---|---|---|
| 마검수 | 3 | 4.9 / 6.3 |
| 흑풍 | 2 | 5.3 / 5.8 |
| 장칠 | 2 | 5.7 / 5.8 |

## 재현 절차
1. `node tools/qa/balance.mjs --n=600 --run=qa-20261126-0921` 를 돌리고 enemies 표를 봅니다.

## 기대 / 실제
- 기대: 위 구역 일반 적은 1구역 일반 이상으로 아프게 때립니다.
- 실제: 평균 피해 5~6 입니다.
- 실험: 마검수 체력 60→72 로 올리면 평균 피해 6.3→9.2, 3구역 돌파율 36.8→34.5% (기준 안) 입니다. 장칠·흑풍은 실험하지 않았습니다.

## 원인 추정
- `src/core/enemies.js:221` 마검수 `maxHp: 60`, `:128` 장칠 `maxHp: 50`, `:146` 흑풍 `maxHp: 46`
- 이 적들은 낮은 층용 easy 목록(`:375`, `:381`)에도 들어 있습니다. 그래서 낮은 층 체력 배율 `scaleForRow`(src/core/run.js:18–)도 같이 봐야 합니다.
