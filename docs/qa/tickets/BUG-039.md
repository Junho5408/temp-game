# BUG-039 손패 카드에서 새 무공 설명 끝줄이 잘림 (BUG-027 재발, smoke F15 구멍)
- 상태: 열림
- 심각도: 보통
- 분류: 화면
- 발견: qa-20261127-1119 · F-EX-01 (+ F-FN-05 의 F15 부분)

## 증상
전투 손패에서 7단계 새 무공의 설명 끝줄이 보이지 않습니다. 숨는 줄에 입마·혈계 같은 **대가 정보**가 들어 있어서, 고를 때 알아야 할 내용을 모르고 씁니다. BUG-027 에서 고친 문제가 새 카드에서 다시 생겼습니다.
- 960×540 에서 392면(연마 전후) 중 186면이 넘치고, 그중 44면은 3줄보다 심합니다.
- 이름이 두 줄로 꺾이면 설명 칸이 8~9px 로 줄어 첫 줄만 남습니다.
- 칼 바꿔 쥐기+(사파 시작 덱): "카드 1장 뽑기"가 안 보임
- 천마해체대법+: "마기 두 배 · 입마 +2 / 소멸"이 안 보임
- 설명이 4줄이면 마지막 줄이 "명중 n%" 표시 뒤로 숨습니다.
- 혈겁(+): "입마 +1"
- 혈진·혈계권·혈채: "혈계 … +n" 수치
- 마신강림+: "(1마다 +n)"
- 매수: "2)"만 따로 한 줄에 남음
- 4줄 카드 목록: bribe, bloodRage+, magiBurst(+), demonDescent(+), oClosingBow(+), oKeenEye+, oAfterglow(+), oManyToOne(+), oSkyOpen(+), uPourHidden(+), dDeathGrip(+), dFatalClaw(+), dNarrowEscape(+), dWoundFist(+), dBloodDebt(+), dBloodWhip(+), dBloodCalamity(+), dLastDrop(+), dMagiEdge(+), dMagiRelease(+)
- 이를 막아야 할 smoke F15 는 이번에 통과했습니다. 손패가 보이지 않는 상태에서 재고 있어서 **어떤 카드도 실패할 수 없기** 때문입니다.

## 재현 절차
1. `node qa-output/qa-20261127-1119/ex-cardshot.cjs dBloodCalamity+ dissolution+ switchGrip+ bribe` 를 돌립니다. 마교로 출발해 첫 전투 손패를 그 카드들로 바꾸고 960×540 으로 찍습니다.
2. 사진에서 마지막 줄이 보이지 않는 것을 확인합니다.
3. 전체 측정: `node qa-output/qa-20261127-1119/ex-cardtext.cjs` (결과 `ex-cardtext.json` 의 over 목록)
4. F15 구멍 확인: `node qa-output/qa-20261127-1119/analyst/probe-f15.cjs`. 손패가 보이는 상태에서 F15 와 같은 측정을 하면 바로 걸립니다.
- 스크린샷: `qa-output/qa-20261127-1119/ui-cards-hand-960x540.png`, `ui-cards-hand-crop.png`

## 기대 / 실제

- 실제: 이름이 두 줄인 카드와 설명이 4줄인 카드는 끝줄이 잘리거나 명중 표시에 가립니다.

| 혈겁+, 매수 | 24px | 29px | 558 | 548 |

## 원인 추정
- 화면
- `src/ui/screens.js:36-42` `fitCardText`: dense·denser 두 단계까지만 줄이고 그 뒤에는 손을 쓰지 않습니다.
- `style.css:1195` `.card .desc { min-height:0; overflow:hidden }`: 넘친 부분을 소리 없이 자릅니다. 칸이 가운데 정렬(style.css:275)이라 위아래가 함께 잘립니다.
- `style.css:251` `.cname`: 이름이 두 줄이 되면 설명 칸이 8~9px 로 줄어듭니다.
- `style.css:891` `.card .hit`: 명중 표시가 아래 5px 에 겹쳐 놓여 마지막 줄을 덮습니다.
- `src/core/cards.js:475-482` `compactLines`: 9자 기준이라 "혈계: 잃은 체력 10마다 +3"(15자) 같은 긴 줄은 합쳐지지 않습니다.
- 도구
- `tools/qa/smoke.cjs:144-176` F15 는 F04 의 `winBattle` 다음에 돕니다. 이때 손패(#hand)가 보상 창 뒤에 숨어 그려지지 않습니다. 글자 사각형이 0개가 되어 아래끝이 0 으로 잡히고, 모든 카드가 통과합니다.

## 수정 방향 (분석가 제안, 골라서 조합)
- 이름이 두 줄이면 이름 글자를 줄이거나, `.cname` 을 한 줄 + 자동 축소로 만듭니다.
- 세 번째 줄이기 단계를 둡니다. 예: 손패에서는 명중 표시를 설명 칸 밖(종류 표시 자리)으로 옮겨 설명 칸을 넓힙니다.
- 혈계 줄을 "혈계 +3/10" 처럼 짧게 씁니다.
- `compactLines` 기준을 높여 "입마 +1" 같은 짧은 대가 줄을 앞줄에 붙입니다.
