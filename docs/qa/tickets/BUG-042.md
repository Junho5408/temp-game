# BUG-042 마신 혈인(마교 두목 보물) 최대 체력 -10 때문에 마교 최종이 낮음
- 상태: 열림
- 심각도: 보통
- 분류: 밸런스
- 발견: qa-20261127-1119 · F-BA-03

## 증상
마교 진엔딩 판 최종 돌파율이 24.5% 로 기준(30%) 아래입니다. 마교 일반 판 최종도 37.9% 로 세 세력 중 가장 낮습니다.
- 귀면 상대 사망률: 마교 62.1%, 정파 35.7%, 사파 41.0%.
- 귀면 전투 측정(1500판):

| 세력 | 시작 체력 / 최대 체력 | 귀면 공격 피해 | 턴 수 |
|---|---|---|---|
| 마교 | 55.0 / **66.5** | 43.0 | 3.6 |
| 정파 | 62.5 / 80.2 | 25.0 | 5.1 |
| 사파 | 56.5 / 81.4 | 31.0 | 5.1 |

- 마교는 최대 체력이 낮아 귀면의 폭발 공격에 빨리 쓰러집니다. 마신 혈인을 들면 체력 대가가 판 끝까지 따라옵니다(강제로 고르면 2구역 42.9%, 대환단은 56.1%).
- 오차 주의: 최종 구역에 들어간 판이 159판뿐이라 24.5% 는 ±6.7%p 입니다. 판단은 귀면 사망률 차이에 더 기댑니다.
- BUG-033(백리현 체력)과 증상은 같지만 원인이 다릅니다.

## 재현 절차
1. `node tools/qa/balance.mjs --n=1200 --true=1 --faction=demonic --run=<이름>` 을 돌립니다.
2. 귀면 전투 분석: `qa-output/qa-20261127-1119/exp/gwim.mjs`

## 기대 / 실제
- 기대: 진엔딩 판 최종 30% 안팎.
- 실제: 24.5%.

## 원인 추정
- `src/core/items.js:289-291` `demonGodSeal` 의 `maxHp: -10`.
- 귀면 체력을 마교 길에서만 낮추는 안은 거의 효과가 없었습니다(215: 진엔딩 23.2, 200: 25.3).

## 제안
- `maxHp: -10` → `-5`, 설명은 "최대 체력 -5, 매 턴 기세 +1·마기 +1".
- 결과(마교): 보통 판 44.6 / 53.2 / 59.7 / 38.4, 진엔딩 판 최종 24.7 → 31.5.
- 체력 대가를 아예 없애는 안(-0)은 3구역 63.8% 로 기준을 넘어 권하지 않습니다.

## 완료 조건
- 사용자가 수치를 승인합니다.
- 마신 혈인 fx 와 설명을 바꿉니다.
- 마교 3000판과 진엔딩 판(최소 3000판)을 다시 재서 진엔딩 판 최종 30% 안팎, 모든 구역 30~60% 를 확인합니다.
- 마신 혈인을 얻으면 최대 체력이 5 줄어드는지 확인하는 규칙 테스트를 추가합니다.
