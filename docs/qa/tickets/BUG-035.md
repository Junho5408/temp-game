# BUG-035 독 터뜨리기(사파 고급 무공)는 가지면 오히려 손해

- 심각도: 보통

- 발견: qa-20261127-0536 · F-BA-04
- 함께 적용: BUG-034, BUG-036 (사파 묶음)

## 증상
독 터뜨리기를 1장 넣으면 사파 1구역이 42.1% → 26.2%(−15.9%p), 2구역이 −8.0%p 입니다(2000판). 모든 세력의 무공 가운데 가장 해롭습니다.
- 원인: 쌓인 중독을 모두 지우고 중독×2 피해로 바꿉니다. 중독은 매 턴 피해를 주므로 대개 그냥 두는 편이 낫습니다.
- 사람에게도 "언제 쓰는지"가 직관적이지 않습니다.
