# BUG-049 입마 경문 설명 "마기 +2"가 실제(1장당 +3)와 헷갈림
- 상태: 수정됨
- 심각도: 낮음
- 분류: 화면
- 발견: qa-20261127-1119 · F-FN-02

## 증상
입마 경문 설명은 "입마 대가 때 마기 +2"입니다. 실제로는 원래 쌓이는 +1 에 +2 가 **더해져** 입마 1장당 +3 입니다(5장 → +15). 설명만 보면 1장당 +2 로 읽힐 수 있습니다. 동작 자체는 의도대로입니다.

## 재현 절차
1. `node qa-output/qa-20261127-1119/extra-check.mjs` 를 돌립니다. 입마 5장을 쥔 채 턴을 끝냅니다.
2. 보물이 없으면 마기 +5, 입마 경문이 있으면 +15 (`curse [ 'madnessSutra' ] { magiGain: 15, ... }`).

## 기대 / 실제
- 기대: 설명만 읽어도 입마 1장에 쌓이는 마기를 알 수 있습니다.
- 실제: "+2"가 추가분인지 합계인지 알 수 없습니다.

## 원인 추정
- `src/core/battle.js:752` `addMagi(s, 1 + tfx(s,'curseMagi'))`, 설명은 `src/core/items.js:279`.

## 완료 조건
- 설명을 "입마 대가 때 마기 +2 더 (1장당 +3), 시작 마기 1"처럼 바꿉니다.
- 화면에서 보물 설명이 칸 안에 들어가는지 확인합니다.
