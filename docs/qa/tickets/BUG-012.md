# BUG-012 체력이 가득해도 운기조식 "휴식 +0" 을 고를 수 있음
- 상태: 열림
- 심각도: 낮음
- 분류: 기능
- 발견: qa-20261126-0921 · F-FN-02

## 증상
체력이 가득할 때도 "휴식 체력 +0 (70 → 70)" 버튼이 눌립니다. 누르면 운기조식 기회가 사라집니다. 연마 대신 실수로 누를 수 있습니다.

## 재현 절차
1. 체력 70/70 으로 운기조식 칸에 들어갑니다.
- 도구로 재현: `extra-checks2.cjs` (Y02)

## 기대 / 실제
- 기대: 회복할 체력이 없으면 휴식 버튼이 꺼지고 "기혈이 이미 충만하다" 가 표시됩니다.
- 실제: `disabled false` 입니다.

## 원인 추정
- `src/ui/screens.js:175–178`: 회복량이 0 이어도 버튼을 켭니다.
- core `restHeal`(run.js:354–360)도 막지 않습니다.

## 완료 조건
- 회복량이 0 이면 휴식 버튼을 끕니다.
- 연마할 카드도 없다면 "떠나기" 버튼을 따로 두어 화면에서 빠져나갈 수 있게 합니다.
- 테스트 추가: 체력이 가득하고 연마할 카드도 없을 때 누를 수 있는 버튼이 하나 이상 있는지 확인합니다.
