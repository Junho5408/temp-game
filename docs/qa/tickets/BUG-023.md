# BUG-023 반격 자세에 표시되는 숫자가 실제로 되받는 피해와 다름
- 상태: 열림
- 심각도: 낮음
- 분류: 화면
- 발견: qa-20261127-0035 · F-FN-01
- 관련: BUG-015 (같은 종류. 그때는 손패 숫자만 고쳤음)

## 증상
적이 "반격 자세"를 쓰면 예고에 "反 반격 5", 상태 칩 설명에 "되받는 피해 5" 처럼 원래 숫자가 나옵니다. 실제로 되받는 피해는 적 기세, 적 흐트러짐(0.75배), 내 내상(1.5배)이 반영되어 다릅니다. 2구역 이상과 고수는 기세가 붙어 있어서 대체로 표시보다 1~3 더 아픕니다.

## 재현 절차
1. `node qa-output/qa-20261127-0035/counter-check.mjs` 를 실행합니다.
   - dummy 적, 기세 2, 반격 5, luck:false 로 기본 검법 1장을 씁니다.
2. 결과: `{"enemyStrength":2,"shownCounter":5,"hpLost":7}`
- 브라우저 확인(S4)에서는 적이 흐트러짐 상태라 표시 5, 실제 3 이었습니다.

## 기대 / 실제
- 기대: 예고와 칩 설명의 반격 숫자가 실제로 되받는 피해와 같습니다.
- 실제: 표시 5, 실제 7 (기세 2) 또는 3 (흐트러짐).

## 원인 추정
- 실제 계산: `src/core/battle.js:382-386` 의 `computeDamage(e, p, e.status.counter)`.
- 표시는 모두 원래 값을 씁니다.
  - `src/core/battle.js:530-543` `intentPreview()`: `damage` 만 computeDamage 로 바꾸고 `counter` 는 그대로입니다.
  - `src/main.js:627` (`反 반격 ${it.counter}`), `src/main.js:637` (예고 title).
  - `src/main.js:47` (STATUS_INFO.counter.tip), `src/main.js:591` (상태 칩 title).
- 반격을 쓰는 적: `src/core/enemies.js` 48, 91, 104, 141, 151, 191, 215, 243, 252행.

## 완료 조건
- core 에 "반격 한 번의 실제 피해"를 돌려주는 함수를 둡니다(`computeDamage(e, s.player, counter)`).
- `intentPreview` 의 counter 와 상태 칩 설명이 이 값을 씁니다. 원래 값과 다르면 손패처럼 색으로 구분합니다(BUG-015 와 같게).
- 예고는 적 차례 전 상태로 계산한 추정치이고, 내 차례 중 상태 칩 값은 정확해야 합니다.
- `tests/` 에 테스트를 추가합니다. 기세 2·반격 5 인 적에서 아래 세 값이 같은지 확인합니다. 흐트러짐 경우와 내상 경우도 하나씩 넣습니다.
  - 새 함수 결과
  - `intentPreview(s).counter`
  - 초식 한 장을 쓴 뒤 실제로 줄어든 체력
